# C++ 24 天术语索引

本文件只负责按学习日导航，不保存正式定义。每个术语的唯一规范定义位于其首次出现日对应的 `docs/glossary/dayXX.md`；每日讲义在首次使用处重复同一句定义并链接到具体条目。

## 使用方法

1. 正在学习某一天：直接打开该日术语文件，与 `days/dayXX.md` 对照阅读。
2. 只记得术语、不记得日期：在 `docs/glossary/` 目录中全文搜索中文名或英文名。
3. 新增术语：先搜索整个 `docs/glossary/` 目录，确认没有既有规范定义，再写入首次出现日文件。
4. 修订定义：同时检查术语文件、首次出现的讲义、练习答案和面试题，禁止留下冲突表述。
