# 第 12 天术语：继承表达什么关系

[上一天术语](day11.md) · [返回术语索引](../glossary.md) · [阅读第 12 天讲义](../../days/day12.md)

本文件只保存第 12 天首次出现术语的规范定义。直观模型和完整推理请结合当天讲义阅读。

### 基类与派生类（base class and derived class）

- **定义**：基类是在类派生关系中被继承的类，派生类是在自身对象中包含相应基类子对象并可增加或调整成员的类。
- **决定什么**：派生关系决定派生对象包含哪些基类子对象、成员查找和访问控制怎样参与，以及哪些指针或引用转换可能成立。
- **不决定什么**：它不自动保证业务上的“是一种”关系合理，也不规定统一的字节布局、对象大小或虚函数表实现。
- **最小示例**：

  ```cpp
  class Sensor {};
  class Lidar : public Sensor {};
  ```

- **常见误解**：认为派生对象只保存新增成员，或认为基类的 `private` 部分根本不存在于派生对象中。

### 公有继承（public inheritance）

- **定义**：公有继承是以 `public` 基类说明符建立的继承关系，它保留基类公开接口的可访问性并允许可访问且无歧义的派生类指针或引用隐式转换为基类指针或引用。
- **决定什么**：它决定继承来的 `public`/`protected` 访问级别以及公开派生到基类转换的可访问性。
- **不决定什么**：它不自动证明行为契约满足可替换关系，也不让派生类直接访问基类 `private` 成员。
- **最小示例**：

  ```cpp
  class Lidar : public Sensor {};
  const Sensor& sensor = lidar;
  ```

- **常见误解**：只为复用几行代码就使用公有继承，或认为 `public` 会把基类所有成员都变成派生类的公开成员。

### 组合（composition）

- **定义**：组合是一个类把另一类型的对象作为成员子对象来表达“拥有或使用”关系的设计方式。
- **决定什么**：成员声明决定外层对象直接包含并管理该成员子对象，构造和析构会按成员规则组合。
- **不决定什么**：组合不会建立外层类型到成员类型的隐式“是一种”转换，也不会自动公开成员对象的接口。
- **最小示例**：

  ```cpp
  class Robot {
      Lidar front_lidar_;
  };
  ```

- **常见误解**：把“Robot 拥有 Lidar”写成 `Robot : public Lidar`，从而错误宣称机器人本身是一种雷达。

### 对象切片（object slicing）

- **定义**：对象切片是用派生类对象按值初始化或赋值基类对象时，只复制对应基类子对象而不保留派生类新增状态的现象。
- **决定什么**：目标基类值对象只具有基类类型的状态和接口，派生类新增成员不会被复制到目标。
- **不决定什么**：对象切片本身通常不是未定义行为，也不表示原派生对象被破坏；引用或指针绑定不创建这种基类值副本。
- **最小示例**：

  ```cpp
  Lidar lidar{7, 64};
  Sensor sensor{lidar};  // sensor 没有 Lidar 的 beam_count
  ```

- **常见误解**：认为 `sensor` 仍是隐藏着完整派生部分的 `Lidar`，或把任何派生到基类转换都叫作切片。

### 虚析构函数（virtual destructor）

- **定义**：虚析构函数是在基类中声明为 `virtual` 的析构函数，使通过基类指针删除派生类对象时按最派生对象开始执行正确析构序列。
- **决定什么**：在允许这种多态删除的常规 C++17 设计中，它使删除表达式先执行派生析构，再完成基类析构与相应释放过程。
- **不决定什么**：它不要求类的所有函数都为虚函数，也不规定编译器必须使用某种虚函数表或对象布局。
- **最小示例**：

  ```cpp
  class Task {
  public:
      virtual ~Task() = default;
  };
  ```

- **常见误解**：认为非虚析构只会稳定地漏掉派生析构而其余行为仍有定义；实际通过不合适的基类指针删除可导致未定义行为。
