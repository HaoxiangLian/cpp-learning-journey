# 第 7 天术语：连续数据、字符串与手动资源管理

[上一天术语](day06.md) · [返回术语索引](../glossary.md) · [阅读第 7 天讲义](../../days/day07.md)

本文件只保存第 7 天首次出现术语的规范定义。直观模型和完整推理请结合当天讲义阅读。

### 数组与数组到指针转换（array and array-to-pointer conversion）

- **定义**：数组是由固定数量、同一元素类型的子对象连续组成的对象；在多数表达式中，数组表达式会转换为指向首元素的指针值，但数组类型并不因此等同于指针类型。
- **决定什么**：数组类型决定元素类型和界限，转换后的指针值提供从首元素开始的间接访问路径。
- **不决定什么**：转换后的指针不自动携带元素数量，函数数组形参中的界限也不形成普通运行时范围检查。
- **最小示例**：

  ```cpp
  int values[3]{1, 2, 3};
  int* first{values};  // 这里发生数组到指针转换
  ```

- **常见误解**：把数组定义成“不可修改的指针”，从而误判 `sizeof`、参数传递和对象布局。

### C 风格字符串（C-style string）

- **定义**：C 风格字符串是以值为零的字符 `\0` 作为终止标记的字符序列；使用它的接口依赖在可访问范围内找到该终止字符。
- **决定什么**：终止字符让只接收起始指针的传统接口能够识别序列结束位置。
- **不决定什么**：任意字符数组不一定是 C 字符串，起始指针本身也不携带可验证的容量。
- **最小示例**：

  ```cpp
  char name[]{"imu"};  // 包含 'i'、'm'、'u'、'\0'
  ```

- **常见误解**：认为 `char name[3]{'i', 'm', 'u'};` 会自动多出一个终止字符。

### `std::string`

- **定义**：`std::string` 是标准库提供的字符串类，它作为对象管理字符序列、当前长度和所需存储，并提供拼接、查询和比较等成员操作。
- **决定什么**：其公开接口提供长度和字符串操作，不要求调用方手工扫描终止字符来确定 `size()`。
- **不决定什么**：标准不保证某一种 small string optimization、对象字段布局或所有操作都不发生分配。
- **最小示例**：

  ```cpp
  std::string task{"inspect"};
  task += "-done";
  ```

- **常见误解**：认为 `std::string` 只是一个 `char*` 别名，或根据某个编译器的内部布局编写可移植代码。

### `new` 与 `delete` 表达式（new-expression and delete-expression）

- **定义**：`new` 与 `delete` 表达式是创建动态存储期对象并结束相应对象生命周期、释放其存储的语言机制；单对象形式与数组形式必须按来源匹配。
- **决定什么**：`new T`/`delete` 与 `new T[n]`/`delete[]` 分别建立正确的对象创建和销毁配对。
- **不决定什么**：裸指针不会自动记录唯一所有者，`delete` 也不会自动把所有保存同一地址的指针设为 `nullptr`。
- **最小示例**：

  ```cpp
  int* values{new int[3]{1, 2, 3}};
  delete[] values;
  values = nullptr;
  ```

- **常见误解**：认为 `new[]` 可以配普通 `delete`，或认为释放失败时必定立刻崩溃。

### `malloc` 与 `free`（malloc and free）

- **定义**：`malloc` 与 `free` 是 C 标准库风格的原始存储分配与释放函数；`malloc` 按字节数请求未初始化存储并以 `void*` 返回，失败时返回空指针，`free` 只接受与该分配族契约相符的指针。
- **决定什么**：这组函数管理相应的原始存储请求与释放，不执行 C++ 类对象的构造和析构。
- **不决定什么**：某实现可能在底层复用分配机制，不代表 `malloc/free` 可以与 `new/delete` 交叉配对。
- **最小示例**：

  ```cpp
  void* raw{std::malloc(128)};
  std::free(raw);
  ```

- **常见误解**：因为某平台的 `operator new` 可能调用 `malloc`，就认为 `free(new T)` 是可移植且合法的。
