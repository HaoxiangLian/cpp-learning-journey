# 第 5 天术语：名字何时可见，对象活多久

[上一天术语](day04.md) · [返回术语索引](../glossary.md) · [阅读第 5 天讲义](../../days/day05.md)

本文件只保存第 5 天首次出现术语的规范定义。直观模型和完整推理请结合当天讲义阅读。

### 作用域（scope）

- **定义**：作用域是与声明关联、决定名称在哪些程序位置能够参与名称查找的程序区域。
- **决定什么**：它决定某个程序位置写下一个未限定名称时，哪些声明可能被找到。
- **不决定什么**：它不决定对象采用哪种存储期，也不等于对象的生命周期。
- **最小示例**：

  ```cpp
  int value{1};
  {
      int value{2};  // 内层声明隐藏外层名称
  }
  ```

- **常见误解**：认为名称离开作用域就足以证明对应对象一定已经不存在，例如忽略局部 `static` 对象。

### 生命周期（lifetime）

- **定义**：生命周期是对象或引用在运行时从其初始化完成并开始存在，到被销毁或其存储被释放、重用而结束的时间区间。
- **决定什么**：它决定程序何时可以按该对象或引用的正常语义使用它。
- **不决定什么**：它不说明名称在源代码哪里可见，也不保证生命周期结束后的错误使用会以某种固定方式失败。
- **最小示例**：

  ```cpp
  {
      int sample{7};  // 初始化完成后，sample 对象的生命周期开始
  }                   // 离开块时，该对象的生命周期结束
  ```

- **常见误解**：把“内存地址中还残留旧比特”当作对象仍处于生命周期内。

### 存储期（storage duration）

- **定义**：存储期是对象的一项属性，它规定承载该对象的存储至少可能持续多久；C++17 区分 static、thread、automatic 和 dynamic storage duration。
- **决定什么**：它描述对象所用存储与程序、线程、块执行或动态分配之间的持续关系。
- **不决定什么**：它不等同于作用域，也不强制实现把对象放入名为“栈”“堆”或“静态区”的固定物理区域。
- **最小示例**：

  ```cpp
  void call() {
      int sample{0};        // automatic storage duration
      static int calls{0};  // static storage duration
  }
  ```

- **常见误解**：把“自动存储期”直接定义成“在栈上”，或把“静态存储期”直接定义成“在数据段中”。

### 链接属性（linkage）

- **定义**：链接属性是名称的一项属性，用来决定位于不同作用域或翻译单元中的声明能否表示同一实体。
- **决定什么**：在 C++17 的本课程范围内，它区分 external linkage、internal linkage 和 no linkage，帮助判断跨声明身份。
- **不决定什么**：它不等于名称可见范围、对象生命周期或构建工具是否成功找到某个库。
- **最小示例**：

  ```cpp
  static int file_limit{80};  // 名称具有 internal linkage
  int shared_limit{100};      // 通常具有 external linkage
  ```

- **常见误解**：认为内部链接表示对象生命周期较短，或认为外部链接表示任意源文件无需声明就能直接使用该名称。

### static（上下文相关说明符）

- **定义**：`static` 是在不同声明位置产生不同语言效果的关键字：块作用域变量因此具有静态存储期，命名空间作用域名称因此具有内部链接，而类的静态成员不属于任何单个对象的普通成员子对象。
- **决定什么**：其具体作用由声明位置决定，可能影响存储期、链接属性或成员与对象的归属关系。
- **不决定什么**：它不统一表示某个固定内存区域，也不会自动让所有读写成为线程安全操作。
- **最小示例**：

  ```cpp
  int next_id() {
      static int id{0};
      return ++id;
  }
  ```

- **常见误解**：用“`static` 就是放在静态区并且全局共享”概括所有上下文。
