# 第 15 天术语：迭代器、算法与 Lambda

本文件只保存第 15 天首次引入术语的规范定义。定义在讲义首次使用处原句重复；请先结合当时的代码和状态变化理解，再用本页复述。

### 迭代器与半开区间（iterator and half-open range）

- **定义**：迭代器是表示序列中某个位置、并按其能力支持访问或移动的对象；半开区间 `[first, last)` 从 `first` 开始，包含到 `last` 之前的元素，但不包含 `last`。
- **决定什么**：一对有效的 `first`、`last` 决定算法处理哪些元素；迭代器自身的能力决定可以解引用、递增或跳转到什么程度。
- **不决定什么**：迭代器不一定是裸指针，也不拥有它所访问的数据；`last` 只标记结束位置，通常不能解引用。
- **最小示例**：

  ```cpp
  int values[]{4, 9, 2};
  auto first = std::begin(values);
  auto last = std::end(values);
  ```

- **常见误解**：把 `last` 当成“最后一个元素”，或认为所有迭代器都支持指针的全部算术操作。

### 标准算法（standard algorithm）

- **定义**：标准算法是标准库中通过迭代器区间等参数执行查找、统计、排序或复制等通用操作的函数模板；算法本身不拥有所处理的数据。
- **决定什么**：具体算法规定输入区间、额外条件、是否修改元素、返回结果和复杂度边界。
- **不决定什么**：算法只接收合法参数并依赖调用者保持区间有效；它不会自动检查 `last` 是否来自同一序列，也不会替调用者保存数据。
- **最小示例**：

  ```cpp
  const auto found = std::find(first, last, 9);
  ```

- **常见误解**：调用 `std::find` 后不与 `last` 比较就直接解引用结果，或认为算法只适用于某一种容器。

### 谓词（predicate）

- **定义**：谓词是能被调用，并针对给定实参返回可按 `bool` 判断结果的可调用对象；算法用它决定某个元素是否满足条件或两个元素的相对关系。
- **决定什么**：传给 `std::count_if` 的一元谓词决定每个元素是否计入结果；传给某些排序算法的二元谓词决定元素顺序。
- **不决定什么**：谓词是一种角色和调用要求，不是一种专属语法；普通函数、函数对象和合适的 Lambda 都可以充当谓词。
- **最小示例**：

  ```cpp
  bool is_even(int value) { return value % 2 == 0; }
  std::count_if(first, last, is_even);
  ```

- **常见误解**：把“谓词”等同于 Lambda，或让本应只判断条件的谓词修改所检查的元素。

### Lambda 表达式与捕获（lambda expression and capture）

- **定义**：Lambda 表达式是在使用处创建简单函数对象的表达式；捕获列表规定 Lambda 函数体能以值副本或引用使用哪些外层局部对象。
- **决定什么**：`[threshold]` 保存创建 Lambda 时的值副本，`[&threshold]` 保存对外层对象的引用；参数列表和函数体决定调用时怎样检查元素。
- **不决定什么**：捕获不会自动包含所有外层名字；引用捕获也不会延长被引用对象的生命周期。
- **最小示例**：

  ```cpp
  const int threshold = 5;
  const auto accepted = [threshold] (int value) {
      return value >= threshold;
  };
  ```

- **常见误解**：认为值捕获会持续读取外层变量的新值，或把局部对象按引用捕获后在其生命周期结束后继续调用 Lambda。

### 迭代器类别（iterator category）

- **定义**：迭代器类别是按迭代器支持的遍历、读写和跳转能力及相应保证划分的能力等级；算法通过类别要求规定可接受的最低迭代器能力。
- **决定什么**：输入迭代器支持单向读取，前向迭代器增加多遍遍历保证，双向迭代器可后退，随机访问迭代器可常量时间跳转；输出迭代器承担写入角色。
- **不决定什么**：更强能力不表示某个算法一定更快，也不能忽略元素本身的比较、交换或移动要求；C++20 的连续迭代器是额外补充，不属于 C++17 的五类主线。
- **最小示例**：

  ```cpp
  std::find(input_first, input_last, 3);  // 输入迭代器足够
  std::sort(std::begin(values), std::end(values));  // 指针支持随机访问
  ```

- **常见误解**：只要两个对象能写成 `first`、`last`，就认为它们必然满足所有标准算法的迭代器要求。
