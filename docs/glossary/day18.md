### `std::unique_ptr` 与 `std::make_unique`（unique pointer and make_unique）

- **定义**：`std::unique_ptr<T>` 是独占管理一个对象或数组的智能指针类型：任一时刻相应资源最多由一个 `unique_ptr` 负责结束，所有权可移动但不可复制；`std::make_unique`（C++14）通过构造参数创建对象并返回管理它的 `unique_ptr`。
- **当日落点**：[Day 18：机制一](../../days/day18.md#机制一unique_ptr-把唯一责任写进类型)
- **决定什么**：类型直接限制管理责任不能复制；移动后由新指针负责，旧指针为空。
- **不决定什么**：它不表示被管理对象一定处在某种物理内存区域，也不表示移动会移动被管理对象本身。
- **最小示例**：`auto next = std::move(owner);`
- **常见误解**：把移动后的源 `unique_ptr` 说成已经不存在；它仍可检查、赋值和销毁，只是不能为空时解引用。

### `std::shared_ptr` 与控制块（shared pointer and control block）

- **定义**：`std::shared_ptr<T>` 是让多个智能指针共同承担同一对象结束责任的类型；与该共享关系关联的控制块保存共享拥有者数量等管理信息，最后一个共享拥有者离开时相应对象被销毁。
- **当日落点**：[Day 18：机制二](../../days/day18.md#机制二shared_ptr-只在确实共同负责时共享)
- **决定什么**：复制建立新的共享拥有者，最后一个共享拥有者离开决定被管理对象结束。
- **不决定什么**：标准不规定控制块的字段排列、ABI 或固定物理布局。
- **最小示例**：`auto second = first;`
- **常见误解**：认为 `shared_ptr` 是无需分析责任的“更安全默认值”，或把一次 `use_count()` 观察当成并发同步。

### `std::weak_ptr`、`lock` 与循环共享（weak pointer, lock and cyclic sharing）

- **定义**：`std::weak_ptr<T>` 是从 `shared_ptr` 共享关系建立、但不增加共享拥有者数量的非拥有观察者；`lock()` 在对象仍存在时返回一个共享拥有者，否则返回空 `shared_ptr`，它常用于打断会让对象彼此长期保留的循环共享。
- **当日落点**：[Day 18：机制三](../../days/day18.md#机制三weak_ptr-安全观察但不延长生命)
- **决定什么**：观察关系不会仅凭自身延长对象生命；访问前可用 `lock()` 安全取得一次共享责任。
- **不决定什么**：`weak_ptr` 不会主动删除循环中的对象，也不能让已经结束的对象复活。
- **最小示例**：`if (auto alive = observer.lock()) { /* 使用 alive */ }`
- **常见误解**：先调用 `expired()` 再假定下一行仍有效；检查与取得使用期应由 `lock()` 一次完成。
