# 第 20 天术语：类型推导、值类别与转发

### `auto` 类型推导（auto type deduction）

- **定义**：`auto` 类型推导是编译器根据初始化表达式和声明中 `auto` 周围的 `const`、`&`、`&&` 等形式确定变量类型的编译期规则。
- **决定什么**：按值的 `auto` 通常不保留初始化表达式类型的顶层 `const` 和引用，`auto&`、`const auto&` 等写法则把引用或只读要求明确写入目标类型。
- **不决定什么**：`auto` 不会让变量失去静态类型，也不保证推导结果与初始化表达式的 `decltype` 完全相同。
- **最小示例**：`const int source{3}; auto copy = source; const auto& view = source;`
- **常见误解**：认为 `auto` 是运行时动态类型，或认为它会无条件保留初始化对象的全部限定。

### `decltype` 类型查询（decltype type query）

- **定义**：`decltype` 类型查询是在不按通常方式求值其操作数的情况下，依照操作数的语法形式和值类别得到一个类型的编译期规则。
- **决定什么**：未加括号的名字通常得到该实体的声明类型；其他表达式为左值时得到 `T&`、为将亡值时得到 `T&&`、为纯右值时得到 `T`。
- **不决定什么**：`decltype` 通常不执行其中表达式，也不表示给名字加括号只是无意义的排版变化。
- **最小示例**：`int value{0}; decltype(value) copy{1}; decltype((value)) alias = value;`
- **常见误解**：认为 `decltype(value)` 与 `decltype((value))` 永远相同，或认为查询类型会调用函数并产生运行时副作用。

### 值类别（value category）

- **定义**：值类别是表达式的一项编译期分类：左值表示可定位的对象或函数，将亡值表示资源可被复用的临近结束对象，纯右值用于初始化对象或计算一个值；将亡值和纯右值合称右值。
- **决定什么**：它参与引用绑定和重载选择，从而决定一个表达式能否匹配 `T&`、`const T&` 或 `T&&` 等入口。
- **不决定什么**：值类别不是对象的物理存储位置，也不等同于类型；有名字的右值引用变量表达式仍是左值。
- **最小示例**：`Packet packet; route(packet); route(Packet{});`
- **常见误解**：把“右值”简单定义为等号右边的东西，或看到变量声明类型含 `&&` 就断言该变量名表达式是右值。

### 转发引用、引用折叠与 `std::forward`（forwarding reference, reference collapsing and std::forward）

- **定义**：转发引用是在类型模板参数由调用实参推导时形如 `T&&` 的函数参数；引用折叠把推导组合中的任意含左值引用情形折叠为左值引用、仅两个右值引用组合成右值引用，`std::forward<T>` 据此保留调用实参原来的值类别。
- **决定什么**：同一个函数模板可以让左值继续匹配左值入口、让右值继续匹配右值入口，而不把所有具名形参都误当成左值传下去。
- **不决定什么**：任意 `T&&` 都不一定是转发引用，`std::forward` 也不执行资源搬运；最终选中的构造、赋值或重载才决定具体操作。
- **最小示例**：`template<class T> void relay(T&& value) { consume(std::forward<T>(value)); }`
- **常见误解**：在非转发语境机械使用 `std::forward`，或认为直接传递具名 `value` 能自动恢复调用者原来的右值性质。
