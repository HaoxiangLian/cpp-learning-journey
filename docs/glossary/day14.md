# 第 14 天术语：模板与实例化

本文件只保存第 14 天首次引入术语的规范定义。定义在讲义首次使用处原句重复；请先结合当时的代码和状态变化理解，再用本页复述。

### 函数模板、模板参数与模板实参（function template, template parameter and template argument）

- **定义**：模板是用参数描述一族函数、类或变量等实体的声明；函数模板是定义一族函数的模板，模板参数是该声明中的占位符，模板实参是某次使用时为占位符提供的类型、值或模板。
- **决定什么**：模板声明说明哪些部分保持不变、哪些部分由模板实参决定；函数模板可据不同实参形成相应函数。
- **不决定什么**：一份函数模板不表示程序运行时只有一个“万能函数”，也不保证模板体中的操作适用于任意类型。
- **最小示例**：

  ```cpp
  template <typename T>
  T larger(T left, T right) {
      return left < right ? right : left;
  }
  ```

- **常见误解**：把 `T` 当成某个固定类型，或认为模板会在运行时根据值的类型临时切换实现。

### 模板实参推导（template argument deduction）

- **定义**：函数模板实参推导是编译器比较函数形参类型与调用实参类型，尝试确定未显式给出的模板实参的过程。
- **决定什么**：它决定调用 `larger(3, 7)` 时能否从两个 `int` 实参得到 `T = int`，以及相应函数模板是否成为可调用候选。
- **不决定什么**：推导不会先随意把相互冲突的类型都转换成一个“共同类型”；显式给出模板实参后发生的普通参数转换是下一步规则。
- **最小示例**：

  ```cpp
  larger(3, 7);          // 推导 T = int
  larger<double>(3, 7);  // 显式给出 T = double
  ```

- **常见误解**：认为 `larger(3, 4.5)` 会自动把 `int` 与 `double` 统一推导为 `double`。

### 模板实例化（template instantiation）

- **定义**：模板实例化是将一组模板实参用于模板，并在程序需要时形成相应具体函数、类或变量定义的过程；由使用自动触发的实例化称为隐式实例化。
- **决定什么**：它决定模板中依赖具体类型的表达式何时针对某组实参接受检查，以及程序何时需要相应具体定义。
- **不决定什么**：实例化不保证最终二进制一定保留一份可观察的独立机器码；内联、合并与删除未使用代码属于实现和优化边界。
- **最小示例**：

  ```cpp
  larger(3, 7);  // 需要时隐式实例化使用 int 的具体函数
  ```

- **常见误解**：认为只要模板声明能被读过，任意类型调用都必然成功，或认为所有错误都必须等到实例化时才检查。

### 类模板（class template）

- **定义**：类模板是以模板参数表示成员类型或其他可变部分、据此定义一族类的模板。
- **决定什么**：它允许相同成员结构和操作用于不同实参形成的具体类类型，例如 `Reading<int>` 与 `Reading<double>`。
- **不决定什么**：不同模板实参形成的类不是同一个类型；它们之间不会因为来自同一类模板就自动赋值或转换。
- **最小示例**：

  ```cpp
  template <typename T>
  class Reading {
      T value_{};
  };
  ```

- **常见误解**：把 `Reading<int>` 和 `Reading<double>` 当成同一类的两个普通对象，并忽略完整类型名中的模板实参。

### 主模板、显式特化、约束与 concept（primary template, explicit specialization, constraint and concept）

- **定义**：主模板是给出一族模板实体一般形式的模板声明；显式特化是为一组完整指定的模板实参另行声明或定义版本，使该组实参不再使用由主模板生成的版本。约束是一组模板实参必须满足的要求；`concept` 是 C++20 用名称表达并可由模板声明引用的约束。
- **决定什么**：显式特化为某个完整实参列表提供例外实现；约束决定模板实参是否满足声明要求，C++20 `concept` 让要求可命名并参与模板选择。
- **不决定什么**：显式特化不是限制所有可接受类型的首选工具；C++17 的 `static_assert` 可检查简单要求，但它不是 C++20 语言约束，也不参与重载候选筛选。
- **最小示例**：

  ```cpp
  template <typename T>
  struct TypeName { static const char* get() { return "other"; } };

  template <>
  struct TypeName<bool> { static const char* get() { return "boolean"; } };
  ```

- **常见误解**：先使用 `TypeName<bool>` 再补显式特化，或把“为一个类型定制行为”和“声明所有允许类型的要求”混为一谈。
