# 第 2 天术语：变量、对象、类型与初始化

[上一天术语](day01.md) · [返回术语索引](../glossary.md) · [阅读第 2 天讲义](../../days/day02.md)

本文件只保存第 2 天首次出现术语的规范定义。直观模型和完整推理请结合当天讲义阅读。

### 对象（object）

- **定义**：对象是程序执行期间占据一段存储、具有类型，并可表示值的实体。
- **决定什么**：对象的类型决定可用操作和表示值时必须遵守的语言规则。
- **不决定什么**：对象不一定有名称；C++ 标准也不保证某个普通对象一定放在寄存器、栈或其他特定硬件区域。
- **最小示例**：

  ```cpp
  int sample_count{0};  // sample_count 所指的是一个 int 对象
  ```

- **常见误解**：把“对象”只理解为类的实例。`int`、`double` 等基本类型也能创建对象。

### 变量（variable）

- **定义**：变量是由声明引入的具名对象或具名引用。
- **决定什么**：变量提供一个名称，使代码可以引用相应对象或引用所绑定的实体。
- **不决定什么**：变量不是“可以随时改变的值”的同义词；`const` 变量也仍然是变量。
- **最小示例**：

  ```cpp
  const int sensor_id{12};  // sensor_id 是变量，所指对象不可被普通赋值修改
  ```

- **常见误解**：认为变量必须可变，或者认为对象和变量是完全相同的概念。

引用是一种别名机制，将在第 6 天展开；这里不提前使用引用规则解释变量。

### 值（value）

- **定义**：值是对象能够表示或表达式求值能够产生的抽象信息。
- **决定什么**：值参与运算、比较和输出时决定相应结果。
- **不决定什么**：值本身不等于保存它的对象，也不等于对象在具体机器上的字节排列。
- **最小示例**：

  ```cpp
  int sample_count{3};  // 对象 sample_count 当前表示值 3
  ```

- **常见误解**：把变量名称、对象和对象当前保存的值当作同一个东西。

### 类型（type）

- **定义**：类型是 C++ 对对象、引用、函数和表达式进行分类的规则系统，它规定可表示的值、允许的操作及相关语义约束。
- **决定什么**：决定哪些操作合法，以及操作如何解释；例如整数类型与浮点类型具有不同的表示和运算规则。
- **不决定什么**：只写 `int` 并不能跨所有实现保证它恰好占 4 字节；具体大小受标准最低要求和实现选择共同约束。
- **最小示例**：

  ```cpp
  int sample_count{3};
  double temperature_celsius{21.75};
  ```

- **常见误解**：认为类型只是“占多少字节”，忽略它还决定合法操作和表达式语义。

### 初始化（initialization）

- **定义**：初始化是在对象被创建时确定其初始状态的过程。
- **决定什么**：决定对象从创建开始拥有什么初始值或状态，以及使用哪种初始化规则。
- **不决定什么**：初始化不是对象创建后的普通赋值；带 `=` 的声明也可能仍然是初始化。
- **最小示例**：

  ```cpp
  int sample_count{0};  // 创建对象并初始化为 0
  ```

- **常见误解**：看到 `int count = 0;` 中的 `=` 就把它叫作赋值。这里整个声明执行的是初始化。

### 赋值（assignment）

- **定义**：赋值是在对象已经完成初始化之后，用赋值运算修改其当前值或状态的操作。
- **决定什么**：决定现有可修改对象在操作完成后的新值或状态。
- **不决定什么**：赋值不会再次创建同一个对象，也不能用于修改不可赋值的 `const` 对象。
- **最小示例**：

  ```cpp
  int sample_count{0};
  sample_count = 1;  // 对已存在的对象赋值
  ```

- **常见误解**：认为初始化和赋值只是两种等价写法；对于类对象，两者甚至可能调用不同的成员函数，第 9—10 天会展开。

### const 限定（const qualification）

- **定义**：`const` 限定表示程序不得通过相应对象的普通访问方式修改其值或状态。
- **决定什么**：决定哪些修改表达式会被语言规则拒绝，并要求 `const` 对象在创建时获得可用初始状态。
- **不决定什么**：`const` 不自动表示值在编译期已知，也不保证实现必须把对象放入只读硬件内存。
- **最小示例**：

  ```cpp
  const int sensor_id{12};
  ```

- **常见误解**：把 `const` 直接等同于“编译期常量”。运行时得到的值也可以用于初始化某些 `const` 对象。
