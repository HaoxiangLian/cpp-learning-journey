# 第 3 天术语：表达式、转换与控制流

[上一天术语](day02.md) · [返回术语索引](../glossary.md) · [阅读第 3 天讲义](../../days/day03.md)

本文件只保存第 3 天首次出现术语的规范定义。直观模型和完整推理请结合当天讲义阅读。

### 表达式（expression）

- **定义**：表达式是规定一次求值的语法构造；求值可以计算一个值、调用函数或修改已有对象。
- **决定什么**：表达式的组成和上下文共同决定代码是否合法，以及求值产生什么结果或操作。
- **不决定什么**：表达式中运算符的优先级只决定语法分组，不能单独证明各部分按什么先后顺序求值。
- **最小示例**：

  ```cpp
  int next_count{sample_count + 1};  // sample_count + 1 是表达式
  ```

- **常见误解**：认为只有包含算术运算符的代码才是表达式；变量名、字面量和函数调用也可以构成表达式。

### 运算符（operator）

- **定义**：运算符是表达式中规定对一个或多个操作数执行何种运算的语法记号或关键字。
- **决定什么**：在操作数类型和上下文给定时，运算符决定要应用的语言运算规则。
- **不决定什么**：看到同一个符号不代表语义永远相同；操作数类型会影响运算，例如整数除法与浮点除法不同。
- **最小示例**：

  ```cpp
  int total{2 + 3};  // + 是运算符，2 和 3 是操作数
  ```

- **常见误解**：把运算符优先级等同于求值先后顺序。

### 类型转换（type conversion）

- **定义**：类型转换是按照 C++ 语言规则把一个类型的值转换成另一类型的值的过程。
- **决定什么**：决定目标类型如何表示转换结果；转换可以由上下文隐式触发，也可以由代码显式请求。
- **不决定什么**：显式写出转换只表达意图，不自动保证结果无精度损失、无范围问题或符合业务含义。
- **最小示例**：

  ```cpp
  double temperature{31.75};
  int whole{static_cast<int>(temperature)};  // 显式转换，结果为 31
  ```

- **常见误解**：认为 `static_cast` 能让所有数值转换变得安全，或者认为隐式转换一定都是错误。

### 短路求值（short-circuit evaluation）

- **定义**：短路求值是 `&&` 和 `||` 从左操作数开始求值，并在左操作数已经决定整个结果时不求值右操作数的规则。
- **决定什么**：`false && right` 不求值 `right`，`true || right` 也不求值 `right`。
- **不决定什么**：短路规则不适用于任意两个并列的子表达式，也不意味着复杂条件越短越清晰。
- **最小示例**：

  ```cpp
  bool valid{count != 0 && total / count > 2};
  ```

- **常见误解**：认为右操作数会先求值，再由 `&&` 或 `||` 丢弃结果。

### 控制流（control flow）

- **定义**：控制流是程序执行时按照语句规则选择下一条要执行语句的过程。
- **决定什么**：条件、分支、循环、`break` 和 `continue` 等语句决定本次执行会走哪条路径。
- **不决定什么**：控制流语句只组织执行路径，不自动保证条件正确、循环终止或每条业务路径都被覆盖。
- **最小示例**：

  ```cpp
  if (temperature >= 30.0) {
      alarm = true;
  }
  ```

- **常见误解**：认为程序能够编译并进入某个分支，就能证明分支条件符合业务需求。
