# 第 8 天术语：类如何维护不变量

[上一天术语](day07.md) · [返回术语索引](../glossary.md) · [阅读第 8 天讲义](../../days/day08.md)

本文件只保存第 8 天首次出现术语的规范定义。直观模型和完整推理请结合当天讲义阅读。

### 类（class）

- **定义**：类是用户定义的类型，它在一个类定义中规定该类型对象所包含的非静态数据成员、可执行的成员函数以及相关访问规则。
- **决定什么**：类定义决定该类型有哪些成员、成员接口如何使用，以及对象必须遵守哪些类内规则。
- **不决定什么**：类不是某个具体对象，也不保证所有成员在内存中紧密排列或采用某一种 ABI 布局。
- **最小示例**：

  ```cpp
  class JointAngle {
      double degrees_{0.0};
  };
  ```

- **常见误解**：把类和对象当成同一个东西，或把类仅理解为“把几个变量放在一起”。

### 成员（member）

- **定义**：成员是在类定义中声明并属于该类的实体；本日重点是保存每个对象状态的非静态数据成员，以及通过对象操作状态的非静态成员函数。
- **决定什么**：成员声明决定对象拥有哪些状态组成部分，以及调用者可通过哪些类内函数读取或改变状态。
- **不决定什么**：成员函数的代码不会为每个对象各复制一份，数据成员也不自动对类外代码公开。
- **最小示例**：

  ```cpp
  class JointAngle {
      double degrees_{0.0};       // 数据成员
      double degrees() const;     // 成员函数
  };
  ```

- **常见误解**：认为每个对象都保存一份成员函数机器代码，或把局部变量误称为类的数据成员。

### 封装与类不变量（encapsulation and class invariant）

- **定义**：封装是把状态及维护该状态的操作组织在类型边界内并限制不受控访问的设计；类不变量是每个对外可观察的有效对象在其公开操作完成前后都应满足的条件。
- **决定什么**：二者共同决定哪些状态组合被视为有效，以及公开接口怎样阻止或拒绝破坏有效状态的修改。
- **不决定什么**：封装不等于把所有成员机械地设为 `private`，不变量也不会仅因写在注释中就被自动检查。
- **最小示例**：

  ```cpp
  bool set(double value) {
      if (value < -180.0 || value > 180.0) return false;
      degrees_ = value;
      return true;
  }
  ```

- **常见误解**：认为“用了 `class` 和 `private` 就已经封装良好”，却仍提供能制造无效状态的公开函数。

### 成员访问控制（member access control）

- **定义**：成员访问控制是通过 `public`、`protected` 和 `private` 规定某个成员声明能够在哪些程序上下文中被命名的语言规则。
- **决定什么**：它决定类外代码能否直接命名某成员；`class` 的成员默认是 `private`，`struct` 的成员默认是 `public`。
- **不决定什么**：访问控制不是运行时权限检查，也不保证私有数据经过序列化、调试器或错误指针访问时具有保密性。
- **最小示例**：

  ```cpp
  class JointAngle {
  public:
      double degrees() const;
  private:
      double degrees_{0.0};
  };
  ```

- **常见误解**：把 `private` 当作数据加密或内存隔离，而不是编译期程序合法性规则。

### this 指针与 const 成员函数（this pointer and const member function）

- **定义**：在非静态成员函数中，`this` 是指向该次调用所作用对象的指针；函数末尾的 `const` 表示通过这次调用不能修改该对象的非 `mutable` 数据成员。
- **决定什么**：`this` 确定未限定成员名对应哪个对象，尾置 `const` 决定该成员函数能否由 `const` 对象调用以及其普通修改权限。
- **不决定什么**：`this` 不是隐藏的数据成员，尾置 `const` 也不保证函数没有任何外部副作用或线程安全。
- **最小示例**：

  ```cpp
  double degrees() const {
      return this->degrees_;
  }
  ```

- **常见误解**：认为 `const` 成员函数“什么都不能改”，或认为静态成员函数也拥有指向某个对象的 `this`。
