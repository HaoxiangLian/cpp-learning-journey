# 第 6 天术语：间接访问与内存模型入门

[上一天术语](day05.md) · [返回术语索引](../glossary.md) · [阅读第 6 天讲义](../../days/day06.md)

本文件只保存第 6 天首次出现术语的规范定义。直观模型和完整推理请结合当天讲义阅读。

### 调用栈与堆（call stack and heap）

- **定义**：调用栈与堆是常见实现中的运行时组织方式：调用栈通常保存活动函数调用所需的记录，堆或自由存储相关机制通常满足运行期分配请求；它们不是 C++17 规定的存储期类别，也不是标准要求的唯一物理布局。
- **决定什么**：在具体平台和实现中，它们帮助解释调用记录、分配成本、空间限制与调试器显示。
- **不决定什么**：它们不能代替 automatic、static 或 dynamic storage duration 的语言定义，也不保证固定地址增长方向或性能结论。
- **最小示例**：

  ```cpp
  void run() {
      int local{7};  // automatic storage duration；常见实现可能使用栈或寄存器
  }
  ```

- **常见误解**：认为“函数里声明”在标准层面就等于“物理存放在栈上”，或认为指针对象本身一定在堆上。

### 指针（pointer）

- **定义**：指针是具有指针类型的对象；对象指针的值可以表示某个对象的地址、数组尾后位置、空指针值或无效指针值，只有满足相应有效性条件时才能通过它间接访问对象。
- **决定什么**：当前指针值决定它是否以及可以对哪个对象进行相应的间接访问。
- **不决定什么**：裸指针类型不自动说明所有权、所指对象的存储期或对象还会存活多久。
- **最小示例**：

  ```cpp
  int value{7};
  int* pointer{&value};
  *pointer = 9;
  ```

- **常见误解**：把指针对象、指针保存的地址值和所指对象当作同一个东西。

### 空指针与 `nullptr`（null pointer and nullptr）

- **定义**：空指针值是不指向任何对象或函数的指针值，`nullptr` 是 C++11 引入、可转换为相应空指针值的专用字面量。
- **决定什么**：接口可以用空指针值明确表达“当前没有目标对象”。
- **不决定什么**：非空不保证指针有效，它仍可能悬空、指向尾后位置或不满足本次访问条件。
- **最小示例**：

  ```cpp
  int* optional{nullptr};
  if (optional != nullptr) {
      *optional = 1;
  }
  ```

- **常见误解**：认为检查 `pointer != nullptr` 就已经证明所有解引用都安全。

### 引用（reference）

- **定义**：引用是初始化时绑定到对象或函数、随后以该被绑定实体的别名参与表达式的语言实体；良定义程序中的引用必须表示有效实体，普通左值引用不能在绑定后改绑到另一个对象。
- **决定什么**：引用绑定决定经由该引用访问的是哪个实体，并可在接口中表达“必须提供对象”。
- **不决定什么**：引用不拥有或延长普通对象生命周期，标准也不规定引用是否必须占用存储。
- **最小示例**：

  ```cpp
  int value{7};
  int& alias{value};
  alias = 9;
  ```

- **常见误解**：把 `alias = other;` 理解成引用改绑，而不是给已绑定对象赋值。

### 悬空指针或引用（dangling pointer or reference）

- **定义**：悬空指针或引用是仍存在但所指或所绑定对象的生命周期已经结束，因而不能再用于正常访问该对象的指针或引用。
- **决定什么**：识别悬空状态可以判断后续对象访问不再满足生命周期前提。
- **不决定什么**：悬空值不保证变为 `nullptr`，错误访问也不保证以崩溃、异常或固定输出呈现。
- **最小示例**：

  ```cpp
  int* pointer{nullptr};
  {
      int local{7};
      pointer = &local;
  }  // pointer 从这里开始悬空
  ```

- **常见误解**：认为非空指针一定有效，或者引用由于语法上不能为 null 就永远不会悬空。
