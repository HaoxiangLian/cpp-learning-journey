# 第 5 天：函数的声明、定义、调用与返回

预计用时：60～90 分钟  
今日目标：把“计算位置误差”封装成函数，并准确区分函数声明、定义、调用、形参与实参。

## 1. 先运行位置误差函数

[function_basics.cpp](../examples/day-05/function_basics.cpp) 的结构如下：

```cpp
double position_error(double target, double current);

int main() {
    const double error{position_error(90.0, 82.5)};
    std::cout << "error: " << error << '\n';
    return 0;
}

double position_error(double target, double current) {
    return target - current;
}
```

输出：

```text
error: 7.5
```

程序只写了一次误差公式。以后需要计算误差时，通过函数名调用它，不必复制整段实现。

### 函数

**函数是具有名称、参数列表、返回类型和函数体的一段可调用代码。**

`position_error` 表达一个明确行为：接收目标值和当前值，返回两者的差。函数让调用方依赖接口，而不必在每次使用时重写计算过程。

### 声明与定义

**函数声明向当前代码说明函数的名称、返回类型和参数类型；函数定义还提供实际函数体。**

```cpp
double position_error(double target, double current);  // 声明
```

分号表示这里只介绍接口。后面的带花括号版本才是定义。编译器处理 `main` 中的调用前必须先看到匹配的声明，否则不知道这个名字表示什么函数。

一次定义规则的跨文件细节在第 12 天讲。本课先记住：同一函数可以在需要处声明，但普通函数实现通常只提供一个定义。

### 形参与实参

**形参是函数接口中接收输入的名字；实参是某次调用时提供给这些形参的表达式。**

在定义中，`target` 和 `current` 是形参；在调用 `position_error(90.0, 82.5)` 中，`90.0` 和 `82.5` 是实参。形参只在函数体内有作用域。

本课形参按值接收，会用实参的值初始化新的形参对象。按值、引用和 `const` 引用的选择在第 6 天专门比较。

### 函数调用

**函数调用是使用函数名和实参请求执行对应函数体的表达式。**

调用发生时，程序准备形参，进入 `position_error` 的函数体，执行其中的语句，得到返回值后回到调用位置。调用表达式本身产生的结果可以继续参与初始化和运算。

### 返回

**返回会结束当前函数调用，并把返回表达式的结果交给调用方。**

`return target - current;` 先计算差值，再把结果作为 `double` 返回。返回类型为 `void` 的函数不返回结果值；非 `void` 函数的正常执行路径必须提供符合返回类型的结果。

## 3. 一次调用具体发生什么

对：

```cpp
const double error{position_error(target_angle, current_angle)};
```

执行顺序可以追踪为：

1. 读取两个实参的值；
2. 用它们初始化形参 `target` 和 `current`；
3. 执行函数体，计算 `target - current`；
4. 返回计算结果；
5. 用返回值初始化调用方的 `error`。

函数调用结束后，本次调用的形参不能再被访问。每次再次调用，都会产生本次调用自己的形参。

## 4. 笔试高频点

### 调用前没有声明

[missing_declaration.cpp](../examples/day-05/missing_declaration.cpp) 把定义放在 `main` 后面，却没有提前声明。编译器按顺序处理到调用处时找不到 `position_error`，因此在编译阶段失败。

### 只改返回类型不能形成两个函数

调用时通常无法仅凭上下文决定应选哪个返回类型，所以 C++ 不允许只靠返回类型区分同名函数。函数重载会在第 6 天讲解。

### 忘记使用返回值

调用 `position_error(target, current);` 可以执行函数，但若既不保存也不使用结果，计算值会被丢弃。编译通过不代表这符合需求。

### 预测

```cpp
int twice(int value) {
    return value * 2;
}

int x{3};
int y{twice(x)};
```

最后 `x` 为 `3`，`y` 为 `6`。按值形参的修改不会自动修改实参对象。

## 5. 面试回答

### 问题：函数声明和定义有什么区别？

> 函数声明告诉编译器函数的名称、返回类型和参数类型，使调用处能够进行名称和类型检查；函数定义还提供真正执行的函数体。声明可以出现在多个需要看到接口的位置，而普通非内联函数的定义通常只在一个源文件中提供，否则可能违反一次定义规则。
