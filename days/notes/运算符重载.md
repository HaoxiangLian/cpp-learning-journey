可以。你现在刚好学到：

```cpp
Data& operator=(const Data& other)
```

所以理解“运算符重载”会非常顺。

C++ 的**运算符重载**，简单说就是：

> 让 `+`、`-`、`=`、`==`、`[]` 等运算符，也能够作用在我们自己定义的类对象上。

比如 `int` 本来就能：

```cpp
int a = 1;
int b = 2;

int c = a + b;
```

但是假设我们自己定义一个类：

```cpp
class Point {
public:
    int x;
    int y;
};
```

那么：

```cpp
Point p1;
Point p2;

Point p3 = p1 + p2;
```

C++ 不知道：

> 两个 `Point` 对象相加，到底是什么意思？

所以我们可以自己规定：

> 两个点相加，就是 `x` 分别相加、`y` 分别相加。

这就是**运算符重载**。

---

## 一、最核心的语法

运算符重载本质上还是一个**函数**。

它的一般形式是：

```cpp
返回值类型 operator运算符(参数)
{
    // 运算规则
}
```

例如重载 `+`：

```cpp
Point operator+(const Point& other)
{
}
```

注意这里：

```cpp
operator+
```

整体就是函数名。

你可以把：

```cpp
operator+
```

理解为：

> “名叫 `+` 的特殊函数”

类似地：

```cpp
operator=
operator-
operator==
operator[]
operator()
```

都是特殊的函数名。

---

# 二、一个完整的 `+` 运算符重载

比如：

```cpp
class Point {
private:
    int x;
    int y;

public:
    Point(int x_, int y_)
        : x(x_), y(y_)
    {
    }

    Point operator+(const Point& other)
    {
        Point result(
            x + other.x,
            y + other.y
        );

        return result;
    }
};
```

然后：

```cpp
Point p1(1, 2);
Point p2(3, 4);

Point p3 = p1 + p2;
```

这里：

```cpp
p1 + p2
```

实际上可以近似理解成：

```cpp
p1.operator+(p2);
```

非常重要。

也就是说：

```cpp
p1 + p2
```

中：

- `p1` 是调用这个成员函数的对象
    
- `p2` 作为参数 `other` 传进去
    

于是：

```cpp
Point operator+(const Point& other)
```

执行的时候：

```cpp
this
```

指向 `p1`。

因此：

```cpp
x + other.x
```

其实等价于：

```cpp
this->x + other.x
```

也就是：

```cpp
p1.x + p2.x
```

---

# 三、把语法拆开看

来看：

```cpp
Point operator+(const Point& other)
```

拆开：

```text
Point        operator+        (const Point& other)
↑               ↑                      ↑
返回值类型      函数名                参数
```

其中：

### 1. `Point`

表示：

> 这个运算最后返回一个 `Point` 对象。

---

### 2. `operator+`

表示：

> 我正在重载 `+` 运算符。

---

### 3. `(const Point& other)`

表示：

> 右边再接收一个 `Point` 对象。

所以：

```cpp
p1 + p2
```

就对应：

```cpp
p1.operator+(p2);
```

---

# 四、为什么成员函数版本只有一个参数？

你可能会疑惑：

```cpp
p1 + p2
```

明明有两个对象：

```text
p1
p2
```

为什么：

```cpp
Point operator+(const Point& other)
```

却只有一个参数？

因为 `p1` 已经通过 `this` 传进来了。

所以：

```cpp
p1 + p2
```

等价于：

```cpp
p1.operator+(p2);
```

对应关系：

```text
p1      → this
p2      → other
```

因此只需要显式写一个参数：

```cpp
const Point& other
```

---

# 五、再看你刚刚学的 `operator=`

你刚才看到的是：

```cpp
Data& operator=(const Data& other)
{
    value = other.value;

    return *this;
}
```

这个本质也是运算符重载。

它重载的是：

```cpp
=
```

所以：

```cpp
Data a;
Data b;

a = b;
```

近似理解为：

```cpp
a.operator=(b);
```

于是：

```text
a      → this
b      → other
```

因此：

```cpp
value = other.value;
```

等价于：

```cpp
this->value = other.value;
```

也就是：

```text
a.value = b.value
```

然后：

```cpp
return *this;
```

返回 `a` 自己。

---

# 六、`==` 运算符重载

比如我们希望：

```cpp
p1 == p2
```

表示：

> 两个点的 `x` 和 `y` 都相等。

可以写：

```cpp
class Point {
private:
    int x;
    int y;

public:
    bool operator==(const Point& other) const
    {
        return x == other.x &&
               y == other.y;
    }
};
```

调用：

```cpp
if (p1 == p2)
{
}
```

实际上近似：

```cpp
if (p1.operator==(p2))
{
}
```

这里返回：

```cpp
bool
```

因为比较的结果只有：

```text
true
false
```

所以：

```cpp
bool operator==(...)
```

---

# 七、`[]` 也可以重载

例如：

```cpp
class Array {
private:
    int data[5];

public:
    int& operator[](int index)
    {
        return data[index];
    }
};
```

于是可以：

```cpp
Array arr;

arr[0] = 10;
```

这里：

```cpp
arr[0]
```

实际上近似：

```cpp
arr.operator[](0);
```

所以：

```cpp
operator[]
```

就是在定义：

> 这个类的对象使用 `[]` 时应该干什么。

---

# 八、`()` 也能重载

甚至：

```cpp
()
```

都可以重载。

例如：

```cpp
class Add {
public:
    int operator()(int a, int b)
    {
        return a + b;
    }
};
```

然后：

```cpp
Add add;

int result = add(3, 5);
```

这里：

```cpp
add(3, 5)
```

实际上调用：

```cpp
add.operator()(3, 5);
```

这种对象叫：

> **函数对象 / 仿函数**

以后 STL 会经常遇到。

---

# 九、运算符重载最重要的理解方法

你以后看到：

```cpp
a + b
```

如果 `a` 是一个类对象，可以尝试理解成：

```cpp
a.operator+(b);
```

看到：

```cpp
a = b;
```

可以尝试理解成：

```cpp
a.operator=(b);
```

看到：

```cpp
a == b;
```

可以理解成：

```cpp
a.operator==(b);
```

看到：

```cpp
a[3];
```

可以理解成：

```cpp
a.operator[](3);
```

这是目前最重要的思维方式。

# 十、一个通用公式

成员函数形式：

```cpp
返回类型 operator运算符(右操作数)
{
}
```

例如：

```cpp
A operator+(const A& other);
```

对应：

```cpp
a + b
```

近似：

```cpp
a.operator+(b);
```

所以：

```text
左操作数 a → this
右操作数 b → 参数 other
```

这是你目前最值得记住的公式。

---

# 十一、运算符重载不是创造新运算符

C++ 只允许你重载已经存在的运算符。

例如可以：

```cpp
+
-
*
/
=
==
[]
()
<<
>>
```

但你不能自己创造：

```cpp
***
%%%
@+
```

这种新的运算符。

---

# 十二、也不能改变运算符原来的优先级

假设：

```cpp
a + b * c
```

即使你重载了 `+` 和 `*`，C++ 仍然按照原来的优先级：

```text
* 高于 +
```

所以仍然是：

```cpp
a + (b * c)
```

你不能通过重载把 `+` 变得比 `*` 优先。

---

# 十三、运算符重载的本质

最重要的一句话：

> **运算符重载，本质就是给类写一个特殊名字的函数。**

普通函数：

```cpp
Point add(const Point& other);
```

运算符函数：

```cpp
Point operator+(const Point& other);
```

区别只是：

有了：

```cpp
operator+
```

以后可以写得更加自然：

```cpp
p1 + p2
```

而不需要：

```cpp
p1.add(p2)
```

---

你现阶段尤其可以先把下面 4 个记牢：

```cpp
operator=      // =
operator+      // +
operator==     // ==
operator[]     // []
```

以及这个核心规律：

```cpp
a + b
```

近似：

```cpp
a.operator+(b);
```

而：

```cpp
a = b
```

近似：

```cpp
a.operator=(b);
```

所以**成员函数形式的二元运算符重载中，左边对象通常就是 `this`，右边对象通常作为参数传入。**

这也正好解释了你前面学的：

```cpp
Data& operator=(const Data& other)
{
    this->value = other.value;
    return *this;
}
```

其中 `this` 是左边的 `Data` 对象，`other` 是右边的 `Data` 对象。
