**`const` 成员函数只承诺“不修改自己肚子里的东西”，但它不管“外面的世界”。**

我们把底层的逻辑掰开来看：

### 为什么不能执行 `degrees_ = 10.0`？（管辖区内，严禁造次）

当你在一个成员函数后面加上 `const` 时，编译器在底层做了一件非常绝绝子的事：它把隐藏的 `this` 指针（也就是指向当前对象自己的那个指针）给**锁死**了。

- 在普通函数里，`this` 是：`JointAngle*`（可读可写）。
    
- 在 `const` 函数里，`this` 被降级成了：`const JointAngle*`（只读）。

所以，当你在代码里写下 `degrees_ = 10.0;` 时，编译器把它翻译成底层代码其实是：

C++

```
this->degrees_ = 10.0; 
```

编译器一看，`this` 指向的是一个被 `const` 锁死的区域，你居然想往里面写数据？这直接违反了内存保护协议，于是当场报错拦截。
