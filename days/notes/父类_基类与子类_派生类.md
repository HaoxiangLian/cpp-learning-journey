在 C++ 中，**父类**就是“被其他类继承的那个类”。更正式的名字叫 **基类（Base Class）**；继承它的类叫 **子类 / 派生类（Derived Class）**。

例如：

```cpp
class Animal {
public:
    void eat() {
        std::cout << "吃东西\n";
    }
};

class Dog : public Animal {
public:
    void bark() {
        std::cout << "汪汪\n";
    }
};
```

这里：

- `Animal` 是父类 / 基类
    
- `Dog` 是子类 / 派生类
    
- `Dog : public Animal` 表示：**Dog 继承 Animal**
    

因此：

```cpp
Dog dog;

dog.bark();  // Dog 自己的函数
dog.eat();   // 从 Animal 继承来的函数
```

可以把它理解为一种“**是一个（is-a）**”的关系：

> `Dog` 是一种 `Animal`

所以 `Dog` 在拥有自己特性的同时，还可以继承 `Animal` 中允许继承和访问的成员。

再看一个机器人相关的例子：

```cpp
class Robot {
public:
    void move() {
        std::cout << "机器人移动\n";
    }
};

class SurgicalRobot : public Robot {
public:
    void operate() {
        std::cout << "执行手术操作\n";
    }
};
```

这里可以理解为：

```text
Robot                ← 父类 / 基类
  ↑
  │ 继承
  │
SurgicalRobot        ← 子类 / 派生类
```

`SurgicalRobot` **本身也是一种 Robot**，所以它既可以：

```cpp
SurgicalRobot robot;

robot.move();      // 父类提供的能力
robot.operate();   // 自己新增的能力
```

### 一句话记忆

**父类 = 提供公共属性和功能，供其他类继承的类。**

例如：

```cpp
class Child : public Parent
```

读作：

> `Child` 继承 `Parent`

其中 **`Parent` 是父类，`Child` 是子类**。

另外，C++ 教材和面试里通常更推荐说“**基类和派生类**”，而不是“父类和子类”，但意思基本对应。
