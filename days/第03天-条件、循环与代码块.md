## 先读：关键术语导航

> 本单元大量使用“分支、循环、条件”等日常词。下表把直观说法和 C++ 语言中的准确位置对应起来。

| 术语 | 新手先这样理解 | 专业上更准确地说 |
|---|---|---|
| **控制流（control flow）** | 程序中的语句实际按什么顺序执行 | 控制流描述程序执行时控制在各条语句和函数之间转移的次序。选择、循环、函数调用和跳转都会改变简单的顺序执行。 |
| **条件（condition）** | 用来回答“成立还是不成立”的表达式 | 在 <code>if</code>、<code>while</code> 等语句中，条件会按规则转换为 <code>bool</code>。它不一定原本就是 <code>bool</code>；例如整数 0 转为假，非 0 转为真。 |
| **比较运算符** | 比较两个值的关系，例如相等或大小 | <code>==</code>、<code>!=</code>、<code>&lt;</code>、<code>&lt;=</code>、<code>&gt;</code>、<code>&gt;=</code> 对操作数执行比较并产生布尔结果；它们与赋值运算符 <code>=</code> 完全不同。 |
| **逻辑运算符** | 把多个真假条件组合起来 | 逻辑与、逻辑或和逻辑非先按规则取得布尔意义，再产生 <code>bool</code> 结果。逻辑与和逻辑或具有短路求值行为。 |
| **短路求值（short-circuit evaluation）** | 左边已经能决定结果时，右边就不再执行 | 对逻辑与，左操作数为假时不求值右操作数；对逻辑或，左操作数为真时不求值右操作数。这是语言保证，不只是优化。 |
| **选择语句（selection statement）** | 根据条件选择一条执行路线 | <code>if</code> 和 <code>switch</code> 都是 C++ 选择语句。日常所说“分支”是对不同可选执行路径的形象称呼。 |
| **迭代语句（iteration statement）** | 满足规则时反复执行同一段代码 | <code>while</code>、<code>do while</code> 和 <code>for</code> 是 C++ 的迭代语句，日常通常统称“循环”。 |
| **复合语句或代码块（compound statement）** | 一对花括号包住的一组语句 | 复合语句由花括号中的语句序列组成，整体上也算一条语句，并引入块作用域。花括号不只是为了排版。 |
| **作用域（scope）** | 某个名字在哪些代码位置能够被找到 | 作用域是名称与程序区域之间的语言规则，决定非限定名称查找能否找到某个声明。作用域不等于对象生命周期，也不直接等于内存存放位置。 |
| **局部变量（local variable）** | 在函数或代码块内部声明、只供局部代码使用的变量 | 本课程中的局部变量主要指具有块作用域的变量和函数形参。名字离开作用域后不可直接使用，但对象何时销毁属于生命周期问题。 |
| **<code>break</code> 语句** | 立即离开当前循环或 <code>switch</code> | <code>break</code> 是跳转语句，把控制转移到包围它的最内层循环或 <code>switch</code> 之后；它不会自动退出多层循环或整个函数。 |
| **死循环或无限循环** | 循环一直不能正常结束 | 当循环条件始终为真且没有可达的退出控制时，会持续迭代。无限循环有时是有意设计；问题在于它是否符合程序目标并能正确响应退出事件。 |
| **半开区间 <code>[begin, end)</code>** | 包含开头、不包含结尾的一段范围 | 半开区间包含 <code>begin</code> 到 <code>end - 1</code> 的位置，因此元素数量恰好是 <code>end - begin</code>。C++ 下标循环经常用 <code>i &lt; size</code> 表达这种边界。 |
| **差一错误（off-by-one error）** | 循环恰好多执行或少执行一次 | 差一错误是边界条件相差一个单位造成的逻辑错误，常见于混淆元素个数与最后一个合法下标，或混淆 <code>&lt;</code> 与 <code>&lt;=</code>。 |

## 一、程序不一定从头到尾执行所有语句

前两天的程序基本按从上到下的顺序执行：

```cpp
std::cin >> battery_level;
std::cout << battery_level << '\n';
```

机器人程序还需要做出选择：

- 电量太低时停止
- 温度正常时继续
- 用户选择不同模式时执行不同操作
- 一个动作重复执行指定次数

能够改变简单顺序执行的结构通常称为**控制流结构**。今天学习两类：

- **选择语句**：根据条件选择执行路线，例如 `if` 和 `switch`
- **迭代语句**：按条件重复执行代码，例如 `while` 和 `for`

“条件语句”和“循环语句”是常见通俗说法；选择语句、迭代语句更接近 C++ 标准术语。

## 二、条件按规则取得布尔结果

本单元先使用表达式作为条件。条件位置会按语言规则取得 `bool` 意义，因此条件表达式本身不一定原本就是 `bool` 类型。

例如：

```cpp
battery_level < 20.0
```

如果 `battery_level` 是 `15.0`，结果为 `true`；如果是 `80.0`，结果为 `false`。

### 比较运算符

| 运算符 | 含义 | 示例 |
|---|---|---|
| `==` | 等于 | `mode == 1` |
| `!=` | 不等于 | `mode != 0` |
| `<` | 小于 | `temperature < 80.0` |
| `<=` | 小于或等于 | `speed <= 10.0` |
| `>` | 大于 | `angle > 90.0` |
| `>=` | 大于或等于 | `battery >= 20.0` |

### `=` 和 `==` 完全不同

```cpp
mode = 1;   // 赋值：把 1 保存到 mode
mode == 1;  // 比较：判断 mode 是否等于 1
```

在条件中判断相等时，要使用两个等号：

```cpp
if (mode == 1) {
    std::cout << "Manual mode\n";
}
```

## 三、用逻辑运算组合条件

### `&&`：并且

两边都为 `true`，整个条件才为 `true`：

```cpp
temperature >= 0.0 && temperature <= 80.0
```

表示温度同时满足“不低于 0”和“不高于 80”。

### `||`：或者

至少一边为 `true`，整个条件就为 `true`：

```cpp
battery_level < 0.0 || battery_level > 100.0
```

表示电量小于 `0` 或大于 `100`，输入不在合理范围内。

### `!`：取反

```cpp
bool ready{false};

if (!ready) {
    std::cout << "Robot is not ready\n";
}
```

`!ready` 可以读作“不是 ready”或“ready 为假”。

| 表达式 | 什么时候为真 |
|---|---|
| `a && b` | `a` 和 `b` 都为真 |
| `a || b` | `a`、`b` 至少一个为真 |
| `!a` | `a` 为假 |

条件较长时，使用括号让意图更清楚：

```cpp
if ((temperature < 0.0) || (temperature > 80.0)) {
    std::cout << "Temperature out of range\n";
}
```

> 今天先掌握真假组合。`&&` 和 `||` 还具有短路求值规则，右侧表达式不一定执行；副作用和精确求值顺序在第 14 天补齐（`G12`）。

## 四、`if`：条件为真时才执行

最小形式：

```cpp
if (battery_level < 20.0) {
    std::cout << "Low battery\n";
}
```

执行过程：

1. 计算括号中的条件
2. 条件为 `true`，执行花括号中的语句
3. 条件为 `false`，跳过花括号中的语句

即使代码块中暂时只有一条语句，课程也统一保留花括号，减少以后添加语句时出错的机会。

---

## 五、`if` 和 `else`：二选一

```cpp
if (battery_level >= 20.0) {
    std::cout << "Robot can start\n";
} else {
    std::cout << "Robot must stop\n";
}
```

两条路线中只会执行一条：

| `battery_level` | 条件 `>= 20.0` | 输出 |
|---:|---|---|
| 80.0 | `true` | `Robot can start` |
| 10.0 | `false` | `Robot must stop` |

## 六、`else if`：从多个区间中选择一个

```cpp
if (battery_level < 20.0) {
    std::cout << "Critical\n";
} else if (battery_level < 50.0) {
    std::cout << "Low\n";
} else {
    std::cout << "Normal\n";
}
```

程序从上到下检查，遇到第一个为真的条件后执行对应代码块，然后跳过整条判断链的其余部分。

例如 `battery_level` 为 `35.0`：

1. `35.0 < 20.0` 为假
2. `35.0 < 50.0` 为真
3. 输出 `Low`
4. 不再执行最后的 `else`

条件顺序很重要。下面的顺序有问题：

```cpp
if (battery_level < 50.0) {
    std::cout << "Low\n";
} else if (battery_level < 20.0) {
    std::cout << "Critical\n";
}
```

当电量为 `10.0` 时，第一个条件已经为真，第二个条件永远没有机会执行。应先判断更小、更特殊的范围。

## 七、代码块和作用域

一对花括号包围的部分叫作**代码块**：

```cpp
{
    int value{10};
    std::cout << value << '\n';
}
```

变量名能被使用的代码区域叫作它的**作用域**。

```cpp
if (true) {
    int warning_code{7};
    std::cout << warning_code << '\n'; // 可以
}

std::cout << warning_code << '\n';     // 错误
```

`warning_code` 在 `if` 的代码块内创建，只能在这个代码块中通过该名字访问。离开右花括号后，这个名字就超出作用域了。

> 这里严格说明的是**名字的作用域**。对象的生命周期通常也会在离开该代码块时结束，但“作用域”和“生命周期”不是同一个概念；第 11、17 天会分开讨论（`G11`）。

外层定义的变量可以在内层代码块中使用：

```cpp
int speed{10};

if (speed > 0) {
    std::cout << speed << '\n'; // 可以访问外层的 speed
}
```

初学阶段不要在内层重复定义同名变量：

```cpp
int speed{10};

if (speed > 0) {
    int speed{20}; // 新变量遮住了外层同名变量，容易混淆
}
```

## 八、`switch`：在几个明确选项中选择

当一个整数或字符只对应几个固定选项时，可以使用 `switch`：

```cpp
int mode{2};

switch (mode) {
    case 1:
        std::cout << "Manual\n";
        break;
    case 2:
        std::cout << "Automatic\n";
        break;
    default:
        std::cout << "Unknown\n";
        break;
}
```

可以这样读：

1. 查看 `mode` 的值
2. 值为 `1` 时从 `case 1` 开始
3. 值为 `2` 时从 `case 2` 开始
4. 都不匹配时从 `default` 开始

### 为什么需要 `break`？

`break` 会结束当前 `switch`。如果漏掉它，程序会继续向下执行后续 `case` 的语句，这叫作贯穿。

初学阶段，每个普通 `case` 结尾都写 `break`。

`switch` 适合固定选项，不适合直接判断范围。电量是否低于 `20.0` 仍应使用 `if`。

## 九、`while`：条件为真就继续重复

```cpp
int count{1};

while (count <= 3) {
    std::cout << count << '\n';
    count = count + 1;
}
```

输出：

```text
1
2
3
```

每次循环过程：

1. 检查 `count <= 3`
2. 为真时执行代码块
3. 修改 `count`
4. 回到条件再次检查

如果条件一开始就是假，循环一次也不会执行。

### 小心死循环

下面的循环没有修改 `count`：

```cpp
int count{1};

while (count <= 3) {
    std::cout << count << '\n';
}
```

`count` 永远是 `1`，条件永远为真，程序会不停输出。这叫作**死循环**。

## 十、`for`：适合已知重复次数

如果已经知道要执行几次，`for` 通常更紧凑：

```cpp
for (int cycle{1}; cycle <= 3; ++cycle) {
    std::cout << "Cycle " << cycle << '\n';
}
```

输出：

```text
Cycle 1
Cycle 2
Cycle 3
```

括号中有三部分：

```cpp
for (初始化; 条件; 每轮结束后的更新)
```

对应到示例：

| 部分 | 代码 | 作用 |
|---|---|---|
| 初始化 | `int cycle{1}` | 循环开始前创建计数变量 |
| 条件 | `cycle <= 3` | 每轮开始前决定是否继续 |
| 更新 | `++cycle` | 每轮结束后让 `cycle` 增加 1 |

`++cycle` 在这个只关心计数结果的场景中，可以暂时按下面的效果理解：

```cpp
cycle = cycle + 1;
```

> 这是明确标注的近似，不是说两个表达式在所有语境中完全等价。前置/后置自增的表达式结果和运算符重载在第 14、25 天补齐（`G13`）。

循环变量 `cycle` 的作用域是整个 `for` 语句，循环结束后不能再通过这个名字访问它。

### `<` 与 `<=` 会影响执行次数

```cpp
for (int i{0}; i < 3; ++i)  // i 是 0、1、2，共 3 次
```

```cpp
for (int i{0}; i <= 3; ++i) // i 是 0、1、2、3，共 4 次
```

这种差一轮的问题叫作边界错误，是循环中最常见的错误之一。

---

## 十一、`while` 还是 `for`？

| 情况 | 更自然的选择 |
|---|---|
| 已知重复次数 | `for` |
| 不知道次数，只知道继续条件 | `while` |
| 根据条件选择一次执行路线 | `if` |
| 一个整数或字符对应固定选项 | `switch` |

这不是强制规则，而是帮助代码表达意图。

## 十二、完整示例：机器人运行控制

仓库示例：[robot_control.cpp](../examples/day-03/robot_control.cpp)

程序将：

1. 读取电量、控制模式和运行次数

3. 根据电量决定能否运行
4. 根据模式输出控制方式

```cpp
    std::cout << "Running cycle " << cycle << '\n';
}
```

输入：

```text

2
3
```

关键输出：

```text
Battery status: normal
Control mode: automatic
Running cycle 1
Running cycle 2
Running cycle 3
Task finished
```

## 十三、常见错误

### 错误 1：把比较写成赋值

```cpp
if (mode = 1) {
}
```

这里修改了 `mode`，没有表达“是否等于 1”。应写：

```cpp
if (mode == 1) {
}
```

### 错误 2：条件后的分号

```cpp
if (battery_level < 20.0); {
    std::cout << "Low battery\n";
}
```

多出的分号结束了 `if` 所控制的语句，后面的代码块会直接执行。应删除分号。

### 错误 3：漏写 `switch` 的 `break`

```cpp
case 1:
    std::cout << "Manual\n";
case 2:
    std::cout << "Automatic\n";
```

选择 `1` 时可能连续输出两行。初学阶段在每个普通 `case` 末尾写 `break`。

### 错误 4：循环变量没有变化

```cpp
while (count < 3) {
    std::cout << count << '\n';
}
```

如果 `count` 不改变，条件可能永远为真。

### 错误 5：边界多执行或少执行一次

写循环前先在纸上列出计数变量会取到的值，例如：

```text
1, 2, 3
```

再决定使用 `<` 还是 `<=`。

### 错误 6：在作用域外使用局部变量

```cpp
if (true) {
    int code{7};
}

std::cout << code << '\n'; // code 在这里不可见
```

## 十四、不必逐字背定义

你可以使用下面的三句话解释新概念：

1. 它解决什么问题？
2. 程序根据什么决定？
3. 最终会执行什么？

例如解释 `if`：

> `if` 用来让程序根据条件做选择。程序先计算括号中的真假结果，为真时执行对应代码块。

解释 `for`：

> `for` 用来重复执行代码。它通过初始值、继续条件和每轮更新控制重复次数。

能准确说明作用和执行过程，比背出教材原句更重要。
