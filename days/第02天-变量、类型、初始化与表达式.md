## 一、实际问题：程序怎样记住数据？

第 1 天的程序只能输出写死的文字：

```cpp
std::cout << "Robot learning started!\n";
```

真实的机器人程序还需要记住许多会变化的数据，例如：

- 机器人名称
- 关节数量
- 目标角度
- 当前速度
- 是否已经启动

C++ 使用[**变量**](#术语-d02-03-变量)保存这些数据。

例如：

```cpp
int joint_count{6};
```

可以先把它读成：

> 创建一个名为 `joint_count` 的变量，它保存整数，初始值是 `6`。

## 二、核心术语：在讲解中建立定义

### 1. [值](#术语-d02-01-值)

值就是程序处理的具体数据，例如：

```text
6
45.5
Z
true
Robot-A
```

### 2. 变量

新手可以先把变量理解为“用名字访问某项数据”。专业上更准确地说，变量是由声明引入的具名实体，通常命名一个对象或引用；因此“有名字的数据盒子”只能作为入门类比，不能代替完整定义。

例如：

```cpp
int joint_count{6};
```

- 变量名：`joint_count`
- 当前保存的值：`6`

变量的值通常可以在程序运行过程中改变。

### 3. [类型](#术语-d02-04-类型)

类型告诉编译器：

- 这个变量准备保存哪一类数据
- 可以对它进行哪些操作
- 编译器应该怎样解释这份数据

例如：

```cpp
int joint_count{6};
double angle{45.5};
```

`joint_count` 保存整数，`angle` 保存带小数的数。

### 4. 变量名

变量名是程序员给变量起的名字，也叫标识符。

推荐使用能够说明用途的名字：

```cpp
int joint_count{6};  // 清楚
int x{6};            // 能用，但含义不清楚
```

变量名：

- 可以包含字母、数字和下划线
- 不能以数字开头
- 不能包含空格
- 不能使用 `int`、`return` 等 C++ 关键字
- 区分大小写，`speed` 和 `Speed` 是两个不同的名字

### 5. [初始化](#术语-d02-07-初始化)

初始化是：

> 创建变量时，为它提供最开始的值。

```cpp
int speed{10};
```

这里的 `10` 是 `speed` 的初始值。

### 6. [表达式](#术语-d02-10-表达式)

表达式是一段能够计算出一个值的代码。

```cpp
speed + 5
```

如果 `speed` 当前为 `10`，这个表达式的结果就是 `15`。

## 三、读懂一条变量定义

本节代码中的 `6`、`3.14` 和 `true` 都是[**字面量**](#术语-d02-09-字面量)：它们是直接写在源代码中、用于表示某个值的记号。字面量是值的一种写法，不是保存该值的变量。

```cpp
int joint_count{6};
```

逐部分解释：

| 部分 | 含义 |
|---|---|
| `int` | 变量的类型，表示整数 |
| `joint_count` | 变量名 |
| `{6}` | 用 `6` 初始化变量 |
| `;` | 这条[语句](#术语-d02-11-语句)结束 |

创建后可以输出它：

```cpp
std::cout << joint_count << '\n';
```

这里不要给变量名加双引号：

```cpp
std::cout << joint_count << '\n';    // 输出变量保存的值：6
std::cout << "joint_count" << '\n';  // 输出文字：joint_count
```

## 四、五种常用类型

### 1. `int`：整数

```cpp
int joint_count{6};
int error_code{-1};
```

适合保存没有小数部分的整数。

### 2. `double`：带小数的数

```cpp
double angle{45.5};
double speed{0.25};
```

初学阶段，遇到需要小数的数值通常优先使用 `double`。

### 3. `char`：单个字符

```cpp
char axis{'Z'};
```

`char` 通常只保存一个字符，并使用**单引号**。

```cpp
char axis{'Z'};       // 单个字符
std::string name{"Z"}; // 一段文本
```

### 4. `bool`：真假

```cpp
bool motor_enabled{true};
bool emergency_stop{false};
```

`bool` 只有两个值：`true` 和 `false`，适合表示“是/否”“开启/关闭”。

### 5. [`std::string`](#术语-d02-14-stdstring)：一段文本

使用 `std::string` 前需要：

```cpp
#include <string>
```

[定义](#术语-d02-06-定义)字符串：

```cpp
std::string robot_name{"Robot-A"};
```

字符串使用**双引号**，可以包含多个字符。

> 当前只学习 `std::string` 的使用接口。它是一个类类型（具体说是类模板特化的别名），涉及构造、资源管理、复制、移动和模板；这些内容在第 19～23、27～28 天补齐。

| 数据 | 合适的类型 | 示例 |
|---|---|---|
| 关节数量 | `int` | `int count{6};` |
| 目标角度 | `double` | `double angle{45.5};` |
| 坐标轴字母 | `char` | `char axis{'Z'};` |
| 是否启动 | `bool` | `bool started{true};` |
| 机器人名称 | `std::string` | `std::string name{"Arm-A"};` |

## 五、初始化和赋值不是同一件事

### 初始化：变量刚创建时获得第一个值

```cpp
int speed{10};
```

此时 `speed` 刚刚被创建，初始值是 `10`。

### [赋值](#术语-d02-08-赋值)：变量已经存在，再修改它保存的值

```cpp
speed = 20;
```

执行过程：

| 时刻 | `speed` 的值 |
|---|---:|
| 初始化之后 | 10 |
| 执行 `speed = 20;` 之后 | 20 |

注意，赋值语句左侧不再写类型：

```cpp
int speed{10}; // 创建并初始化
speed = 20;    // 修改已有变量
```

如果再次写 `int`，含义就不再是“修改原变量”，而是在尝试定义变量。

### 为什么推荐花括号初始化？

这里需要认识[**窄化转换**](#术语-d02-13-窄化转换)：它是可能丢失数值范围或精度的一类转换，例如把 `3.14` 转成 `int`。列表初始化会拒绝其中一部分，从而让潜在的数据丢失更早暴露为编译错误。

本课程默认使用：

```cpp
int count{6};
```

花括号可以帮助编译器阻止某些会丢失信息的初始化：

```cpp
int count{6.8}; // 编译错误：6.8 不能安全地放进 int
```

如果确实需要小数，应选择合适的类型：

```cpp
double count{6.8};
```

### 不要让基本类型变量没有可靠初始值

初学阶段不要这样写：

```cpp
int count;
std::cout << count << '\n';
```

这个局部 `int` 没有得到可靠的初始值，直接读取会产生严重问题。先养成初始化习惯：

```cpp
int count{}; // 初始化为 0
```

更完整的原因会在第 11、14、18 天分别从对象生命周期、未定义行为和工具诊断角度解释。

## 六、表达式和基本[运算符](#术语-d02-12-运算符)

假设：

```cpp
int a{7};
int b{2};
```

| 运算 | 写法 | 结果 |
|---|---|---:|
| 加法 | `a + b` | 9 |
| 减法 | `a - b` | 5 |
| 乘法 | `a * b` | 14 |
| 整数除法 | `a / b` | 3 |
| 取余 | `a % b` | 1 |

可以用表达式初始化另一个变量：

```cpp
int sum{a + b};
```

右侧的 `a + b` 先计算出 `9`，再用结果初始化 `sum`。

### 整数除法会舍去小数部分

```cpp
int result{7 / 2};
std::cout << result << '\n'; // 输出 3
```

因为 `7` 和 `2` 都是整数，使用的是整数除法。

想得到 `3.5`，至少让参与除法的数是小数类型：

```cpp
double result{7.0 / 2.0};
```

### `%` 表示取余

```cpp
int remainder{7 % 2}; // 结果为 1
```

初学阶段只对整数使用 `%`。

### 使用括号明确顺序

```cpp
int result1{2 + 3 * 4};   // 14
int result2{(2 + 3) * 4}; // 20
```

乘除通常先于加减。拿不准时使用括号明确自己的意图。

### 除数不能为零

```cpp
int result{10 / 0}; // 错误做法
```

暂时先记住：除法和取余的右侧不能为 `0`。第 3 天学习 `if` 后，我们会检查输入是否为零。

## 八、完整示例：机器人目标角度

仓库示例：[variables.cpp](../examples/day-02/variables.cpp)

```cpp
#include <iostream>
#include <string>

int main() {
    std::string robot_name{};
    int joint_count{};
    double target_angle{};

    std::cout << "Robot name (no spaces): ";
    std::cin >> robot_name;

    std::cout << "Joint count: ";
    std::cin >> joint_count;

    std::cout << "Target angle for each joint: ";
    std::cin >> target_angle;

    double total_target_angle{joint_count * target_angle};

    std::cout << "\nRobot: " << robot_name << '\n';
    std::cout << "Joints: " << joint_count << '\n';
    std::cout << "Target angle: " << target_angle << '\n';
    std::cout << "Total target angle: " << total_target_angle << '\n';

    return 0;
}
```

如果依次输入：

```text
Arm-A
6
45.5
```

关键计算为：

```cpp
joint_count * target_angle
```

也就是：

```text
6 × 45.5 = 273
```

程序会把结果保存到 `total_target_angle`。

## 九、跟踪变量变化

阅读：

```cpp
int speed{10};
int increase{5};
speed = speed + increase;
int doubled{speed * 2};
```

按顺序跟踪：

| 执行完的语句 | `speed` | `increase` | `doubled` |
|---|---:|---:|---:|
| `int speed{10};` | 10 | 尚未创建 | 尚未创建 |
| `int increase{5};` | 10 | 5 | 尚未创建 |
| `speed = speed + increase;` | 15 | 5 | 尚未创建 |
| `int doubled{speed * 2};` | 15 | 5 | 30 |

其中：

```cpp
speed = speed + increase;
```

不是数学等式，而是一条赋值语句。它的执行顺序是：

1. 读取右侧旧的 `speed`，得到 `10`
2. 计算 `10 + 5`，得到 `15`
3. 把 `15` 保存回左侧的 `speed`

## 十、常见错误

### 错误 1：使用尚未定义的变量

```cpp
speed = 10; // 前面没有定义 speed
```

应先定义：

```cpp
int speed{10};
```

### 错误 2：字符串和字符的引号混淆

```cpp
char axis{"Z"};              // 错误
std::string name{'Robot'};   // 错误
```

正确：

```cpp
char axis{'Z'};
std::string name{"Robot"};
```

### 错误 3：把小数放入 `int`

```cpp
int angle{45.5}; // 编译错误
```

正确：

```cpp
double angle{45.5};
```

### **错误 4：误以为整数除法会保留小数**

```cpp
double average{7 / 2}; // 结果仍然是 3.0
```

`7 / 2` 会先进行整数除法得到 `3`，之后才转成 `double`。

改为：

```cpp
double average{7.0 / 2.0}; // 3.5
```

## 附录：关键术语卡（查阅用）

###### 术语-d02-01-值

**值（value）**

- **新手先这样理解：** 程序处理的具体数据，例如整数 6 或真假值 <code>true</code>
- **专业上更准确地说：** 值是 C++ 抽象机器中的一项数据，可以由表达式计算得到，也可以表示对象当前保存的状态。值本身不等同于存放它的对象。

###### 术语-d02-02-对象

**对象（object）**

- **新手先这样理解：** 程序运行时真正存在、能够保存状态的东西
- **专业上更准确地说：** 在 C++ 语言模型中，对象是一段具有类型和生命周期的存储区域。函数不是对象，引用本身也不是它所引用的对象；更完整的对象模型在第 11 天学习。

###### 术语-d02-03-变量

**变量（variable）**

- **新手先这样理解：** 用名字访问某项数据，例如 <code>joint_count</code>
- **专业上更准确地说：** 变量是由[声明](#术语-d02-05-声明)引入的具名实体，通常命名一个[对象](#术语-d02-02-对象)或引用。因此“变量就是一块内存”只是一种不完整的入门近似。

###### 术语-d02-04-类型

**类型（type）**

- **新手先这样理解：** 告诉编译器这项数据是什么、能做什么
- **专业上更准确地说：** 类型规定值的类别、允许的操作以及对象应按什么规则被解释。类型还影响表示范围、转换和重载选择，并不只决定“占几个字节”。

###### 术语-d02-05-声明

**声明（declaration）**

- **新手先这样理解：** 告诉编译器某个名字代表什么
- **专业上更准确地说：** 声明把一个或多个名字及其属性引入程序，例如实体种类和类型。声明不一定创建对象，也不一定提供函数体。

###### 术语-d02-06-定义

**定义（definition）**

- **新手先这样理解：** 真正把这个实体完整建立起来
- **专业上更准确地说：** 定义是一类满足语言规则的声明：对象定义建立相应对象，函数定义提供函数体，类定义给出类的完整定义。并非所有声明都是定义。

###### 术语-d02-07-初始化

**初始化（initialization）**

- **新手先这样理解：** 对象刚创建时得到第一个值或状态
- **专业上更准确地说：** 初始化是在对象生命周期开始时确定其初始状态的过程。<code>int count = 6;</code> 中的等号仍属于初始化语法，不是对既有对象的赋值。

###### 术语-d02-08-赋值

**赋值（assignment）**

- **新手先这样理解：** 对象已经存在后，再修改它保存的值
- **专业上更准确地说：** 赋值表达式把右侧结果写入左侧所表示的可修改对象。它发生在对象生命周期已经开始之后，与初始化是两个不同的语言过程。

###### 术语-d02-09-字面量

**字面量（literal）**

- **新手先这样理解：** 直接写在代码里的固定值
- **专业上更准确地说：** 字面量是源代码中直接表示一个值的记号，例如 <code>6</code>、<code>3.14</code>、<code>'Z'</code>、<code>"Robot"</code> 和 <code>true</code>。

###### 术语-d02-10-表达式

**表达式（expression）**

- **新手先这样理解：** 能被计算的一段代码，例如 <code>a + b</code>
- **专业上更准确地说：** 表达式由操作数和运算符等组成，求值时具有类型和值类别，可能产生值，也可能产生修改对象等副作用。表达式不一定单独构成一条完整语句。

###### 术语-d02-11-语句

**语句（statement）**

- **新手先这样理解：** 程序执行的一条完整命令
- **专业上更准确地说：** 语句是控制程序执行的语法单位，例如表达式语句、声明语句、选择语句和循环语句。分号常用于结束某些语句，但并非所有语句都以分号结束。

###### 术语-d02-12-运算符

**运算符（operator）**

- **新手先这样理解：** 表示某种操作的符号或单词，例如加号和 <code>sizeof</code>
- **专业上更准确地说：** 运算符按照语言规则作用于操作数。相同符号在不同类型上可能有不同含义；类类型还可以重载一部分运算符。

###### 术语-d02-13-窄化转换

**窄化转换（narrowing conversion）**

- **新手先这样理解：** 把数据放进“装不下或不够精细”的类型，可能丢信息
- **专业上更准确地说：** 窄化转换是标准定义的一类可能丢失范围或精度的转换。列表初始化会拒绝其中一部分，例如用 <code>6.8</code> 初始化 <code>int</code>；完整规则在第 13 天学习。

###### 术语-d02-14-stdstring

**<code>std::string</code>**

- **新手先这样理解：** 标准库提供的字符串类型，用来保存文本
- **专业上更准确地说：** <code>std::string</code> 是标准库类模板 <code>std::basic_string&lt;char&gt;</code> 的类型别名，不是 C++ 关键字，也不是基本类型。当前先学习其常用接口。
