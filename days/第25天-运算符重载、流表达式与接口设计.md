## 第一遍：先跑、再沿着对象变化（必学）

```cpp
#include <iostream>

struct Vector2 {
    double x{};
    double y{};
};

Vector2 operator+(const Vector2& left, const Vector2& right) {
    return {left.x + right.x, left.y + right.y};
}

std::ostream& operator<<(std::ostream& out, const Vector2& value) {
    return out << '(' << value.x << ", " << value.y << ')';
}

int main() {
    Vector2 a{1.0, 2.0};
    Vector2 b{3.0, 4.0};
    std::cout << "sum = " << (a + b) << '\n';
}
```

## 第二遍：从示例推到可迁移规则

### 1. 运算符重载仍然是函数

编译器先进行名称查找和重载决议，再选择成员或非成员运算符函数。它不会因为写了 `+` 就自动知道二维向量如何相加。

### 2. 什么时候选择成员，什么时候选择非成员

会修改左操作数的 `+=` 自然写成成员；对称的 `+` 常写成非成员，并可复用 `+=`。流左操作数是 `std::ostream`，无法给标准库类型添加成员，因此输出运算符通常是非成员。

### 3. 为什么返回流引用

`out << value` 修改的是现有流对象的状态。返回 `std::ostream&` 后，表达式结果仍代表同一个流，下一次插入才能继续。按值返回流既不符合所有权，也通常不可复制。

### 4. 不要为了炫技重载

若符号语义不自然，使用具名函数更清楚。例如把 `operator+` 写成“连接网络并发送命令”会让调用者误判副作用和成本。

### 5. 与 `std::cout` 的真实关系

`std::cout` 是标准输出流对象，`<<` 是一组重载运算符。字符串、整数和自定义 `Vector2` 分别由不同重载处理，返回流引用形成链式调用。

## 故障实验：故意让程序出错

先不要运行，写下你认为它会在“编译、链接、运行或结果”中的哪一阶段失败。

```cpp
struct Counter { int value{}; };

Counter operator+(const Counter& left, const Counter& right) {
    std::cout << "sending command\n"; // 隐藏副作用
    return {left.value - right.value}; // 还违背加法直觉
}
```

### 根因

这段代码可能通过编译，但接口语义错误。修复不是语法修改，而是让 `+` 表达无隐藏副作用的加法；发送命令应使用具名函数。

> 运算符重载本质是函数重载。它允许自定义类型参与已有运算符语法，但不能改变优先级或创造新符号。设计时应保持运算符的直观语义；对称二元运算常写非成员，修改自身的复合赋值常写成员。流插入返回 `ostream&`，所以 `std::cout << a << b` 能连续工作。

## 附录：关键术语卡（查阅用）

###### 术语-D25-01

**运算符重载**

- 新手先这样理解：为自定义类型规定已有运算符怎样调用函数。
- 更准确地说：运算符重载通过函数声明为至少一个类或枚举操作数定义运算含义；不能创造新运算符，也不能改变优先级、结合性或操作数个数。
- 回到代码定位：找到它改变了哪个对象、哪次调用或哪个构建步骤；不要脱离示例背定义。

###### 术语-D25-02

**成员运算符**

- 新手先这样理解：把左操作数作为当前对象的运算符成员函数。
- 更准确地说：成员运算符拥有隐式对象参数；某些运算符必须是成员，二元对称运算有时更适合非成员。
- 回到代码定位：找到它改变了哪个对象、哪次调用或哪个构建步骤；不要脱离示例背定义。

###### 术语-D25-03

**非成员运算符**

- 新手先这样理解：两个操作数都显式出现在参数列表中的运算符函数。
- 更准确地说：非成员运算符支持左右操作数的对称转换；需要访问私有状态时可通过公开接口或谨慎使用友元。
- 回到代码定位：找到它改变了哪个对象、哪次调用或哪个构建步骤；不要脱离示例背定义。

###### 术语-D25-04

**流插入运算符**

- 新手先这样理解：把对象格式化写入输出流的 `operator<<`。
- 更准确地说：常见签名返回 `std::ostream&`，以便保持流状态并支持链式表达式。
- 回到代码定位：找到它改变了哪个对象、哪次调用或哪个构建步骤；不要脱离示例背定义。

###### 术语-D25-05

**链式表达式**

- 新手先这样理解：前一次运算结果继续作为下一次运算的左操作数。
- 更准确地说：`std::cout << a << b` 按运算符结合规则形成连续调用；每次流插入返回流引用。
- 回到代码定位：找到它改变了哪个对象、哪次调用或哪个构建步骤；不要脱离示例背定义。

###### 术语-D25-06

**接口语义**

- 新手先这样理解：运算符行为应符合使用者对该符号的合理预期。
- 更准确地说：重载不仅要类型正确，还应保持等价关系、修改性、复杂度和异常行为等接口约定。
- 回到代码定位：找到它改变了哪个对象、哪次调用或哪个构建步骤；不要脱离示例背定义。
