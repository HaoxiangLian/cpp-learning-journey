# 第 2 天：变量、类型、初始化与赋值

预计用时：60～90 分钟  
今日目标：用变量保存机器人数据，分清对象创建时的初始化和对象已经存在后的赋值。

## 1. 先运行角度误差程序

打开 [joint_error.cpp](../examples/day-02/joint_error.cpp)。程序先计算一次误差，再更新当前角度并重新计算：

```cpp
int joint_id{2};
double target_angle{90.0};
double current_angle{82.5};
double error{target_angle - current_angle};

current_angle = 88.0;
error = target_angle - current_angle;
```

构建和运行：

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic joint_error.cpp -o joint_error
./joint_error
```

输出：

```text
joint: 2
first error: 7.5
second error: 2
```

### 类型

**类型规定一个值可以表示什么，以及程序允许对它执行哪些操作。**

本课使用两种基本类型：

- `int` 保存整数，例如关节编号 `2`；
- `double` 保存带小数的数值，例如角度 `82.5`。

类型不是装饰。`int` 不能准确保存 `90.5`，而除法、比较和可表示范围也会受到操作数类型影响。

### 对象

**对象是程序运行期间具有类型和存储位置的实体。**

执行到 `double current_angle{82.5};` 时，程序创建一个 `double` 对象，并把它的初始值设为 `82.5`。后续语句可以读取或修改这个对象。

### 变量

**变量是由声明引入的具名对象或引用；本课变量都是具名对象。**

`current_angle` 是名字，通过这个名字可以访问对应对象。名字不是值：对象的值从 `82.5` 改成 `88.0` 后，名字仍然是 `current_angle`。

### 初始化

**初始化是在对象创建时确定其初始状态。**

```cpp
double target_angle{90.0};
double error{target_angle - current_angle};
```

第一行用字面值初始化，第二行先计算表达式，再用结果初始化 `error`。课程默认使用花括号，因为它能拒绝部分可能丢失信息的窄化转换。

局部基本类型对象如果写成 `int count;`，不会自动获得可靠的零值。读取它的未确定值会导致未定义行为。需要从零开始时写 `int count{};`。

### 赋值

**赋值是用新值替换一个已经存在的对象当前保存的值。**

```cpp
current_angle = 88.0;
```

这行没有创建第二个 `current_angle`，只是修改原对象。等号左边必须表示可修改的已有对象。

## 3. 按执行顺序追踪值

| 执行位置 | `target_angle` | `current_angle` | `error` |
|---|---:|---:|---:|
| 三个对象初始化后 | 90.0 | 82.5 | 7.5 |
| `current_angle = 88.0` 后 | 90.0 | 88.0 | 7.5 |
| `error = target_angle - current_angle` 后 | 90.0 | 88.0 | 2.0 |

修改 `current_angle` 不会让 `error` 自动重算。`error` 是独立对象，只有再次执行赋值语句，它的值才改变。

## 4. 笔试高频点

### 初始化不是第一次赋值

`double error{7.5};` 创建对象并初始化；`error = 2.0;` 修改已有对象。类类型中两者可能调用完全不同的函数，因此不能混称。

### 花括号会拒绝明显的窄化

[narrowing_error.cpp](../examples/day-02/narrowing_error.cpp) 中：

```cpp
int angle{90.5};
```

小数部分无法由 `int` 保存，程序应在编译阶段失败。正确选择通常是把对象定义为 `double`；若确实要舍弃小数，应在学完第 3 天的显式转换后清楚表达意图。

### 预测结果

```cpp
int a{3};
int b{a};
a = 8;
```

最后 `a` 为 `8`，`b` 仍为 `3`。用 `a` 初始化 `b` 时，复制的是当时的值，不会建立自动同步关系。

## 5. 面试回答

### 问题：初始化和赋值有什么区别？

> 初始化发生在对象创建时，用来建立对象的初始状态；赋值发生在对象已经存在之后，用新值替换当前值。对基本类型，两者表面上都像“放入一个值”；对类类型，它们可能分别调用构造函数和赋值运算符，所以语义不能混为一谈。

常见追问：

1. 为什么推荐使用花括号初始化？
2. `int count;` 和 `int count{};` 有什么区别？
