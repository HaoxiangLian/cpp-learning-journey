# 高频面试实战：按天答案索引

本目录保存每天两道“高频同类题”的主问题答案和全部连续追问参考答案。请先在当天讲义中独立口述，再打开答案文件核对；不要把答案文件当作脱离语境的背诵清单。

[返回面试题总索引](../question-bank.md) · [返回课程入口](../../README.md)

## 使用方法

1. 完成当天讲义的“高频面试实战”，先录下自己的 30 秒回答。
2. 逐个回答讲义列出的连续追问，并主动说明适用条件与标准边界。
3. 打开对应 `dayXX.md`，先比较结论，再比较推理顺序和失分说法。
4. 把答错的题号记入 `progress.md`，在 +2、+7、+14 天重新口述。
