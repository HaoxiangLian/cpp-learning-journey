## 一、概念判断题

判断正误并用一句话说明理由。

1. `std::move(source)` 会立刻把 `source` 的每个成员清零。
2. 移动构造负责初始化新对象，移动赋值面对的是已经存在的目标对象。
3. 一个对象被移动后一定已经析构，不能再赋新值。
4. 只要写了移动构造，编译器就一定自动生成正确的移动赋值。
5. Rule of Zero 的类可以包含会在析构时释放资源的 `std::vector` 成员。

## 三、小型编程题：可移动、不可复制的样本批次

打开 [`move_only_batch.cpp`](move_only_batch.cpp)，完成 `MoveOnlyBatch`：

- 禁止拷贝构造与拷贝赋值。
- 实现移动构造：新对象接管源数组，源对象变为空批次。
- 实现移动赋值：处理目标旧数组、自移动和源对象复位。
- 在 `main` 中依次测试移动构造与移动赋值。
- 预期核心输出包含 `moved: 4 9`，并能证明两个源对象都处于本类约定的空状态。

限制：本题是为了练习裸资源类的移动路径；工程代码通常优先把资源交给标准库类型，从而采用 Rule of Zero。
