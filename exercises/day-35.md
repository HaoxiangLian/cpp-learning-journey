## B｜可运行编程任务

### 任务

修复两个线程同时递增计数器的数据竞争；分别用 `mutex` 和 `atomic<int>` 实现，连续运行多次都得到 200000。

### 起始代码

```cpp
#include <iostream>
#include <thread>

int main() {
    int counter = 0;
    auto work = [&] {
        for (int i = 0; i < 100000; ++i) {
            ++counter;  // TODO: 修复共享访问
        }
    };
    std::thread a(work);
    std::thread b(work);
    a.join();
    b.join();
    std::cout << counter << "\n";
}
```

### 预期结果

```text
200000
```

- [ ] 两个版本都没有无同步的共享写
- [ ] 所有 thread 析构前均已 join
