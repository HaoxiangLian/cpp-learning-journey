# Day 19 练习：RAII 与异常安全

先完成 `exception_safe_update.cpp`，再查看 `solutions/day19/`。题目文件不包含答案。

## A. 概念判断

判断并说明理由：

1. 函数抛出异常后，其中已经成功构造的局部对象都不会析构。
2. 强异常安全保证表示操作失败时，对外可观察状态保持调用前的样子。
3. 给函数写上 `noexcept` 后，编译器会把函数体内所有 `throw` 变成编译错误。
4. 析构函数适合通过抛出异常报告普通清理失败。
