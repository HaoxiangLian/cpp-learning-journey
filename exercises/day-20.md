## B｜可运行编程任务

### 任务

使用标准 RAII 类型编写 `LogWriter`，构造时打开文件，成员析构自动关闭；在函数中途返回时仍不能泄漏资源。

### 起始代码

```cpp
#include <fstream>
#include <stdexcept>
#include <string>

class LogWriter {
public:
    explicit LogWriter(const std::string& path) : stream_{path} {
        if (!stream_) throw std::runtime_error("open failed");
    }
    void write(const std::string& line) { stream_ << line << '\n'; }
private:
    std::ofstream stream_;
};
```

### 预期结果

```text
正常写入一行；提前返回和异常路径都由成员自动完成关闭
```
