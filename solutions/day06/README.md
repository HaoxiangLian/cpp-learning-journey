## 一、概念判断

1. **错**。自动存储期是语言语义；机器栈是常见实现，不是标准规定的唯一位置。
2. **错**。形参指针对象是副本，但它保存的指针值可以与调用方指针一起指向同一对象；`*target` 修改所指对象。
3. **对**。非空只排除一种状态，还要证明所指对象存在、类型与访问方式有效且没有越界。

## 二、代码分析

### A

输出为 `9 false`。`*target = 9` 修改共同指向的 `value`；`target = nullptr` 只改变按值传入的形参指针，调用方 `pointer` 仍指向 `value`。

### B

引用没有改绑，输出 `8 8`。`alias = second` 等价于给 `first` 赋 `second` 的值。

### C

块外 `pointer` 对象仍处于生命周期内，但 `sample` 对象已经结束生命周期，因此 `pointer` 悬空。随后求值 `*pointer` 试图访问已结束生命周期的对象，行为未定义；不能断言必然崩溃或输出 `42`。
