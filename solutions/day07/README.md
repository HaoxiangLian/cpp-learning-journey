# 第 7 天答案与解析

## 一、概念判断

1. **错**。数组对象含有全部元素，指针对象只保存指针值；数组只在多数表达式中转换成首元素指针。
2. **对**。连续存储是数组语义保证；内建下标越界属于未定义行为，不要求抛异常或诊断。
3. **错**。C 风格字符串必须在可访问范围内含有终止字符 `\0`。
4. **对**。数组与单对象的创建、删除形式必须匹配；不匹配是未定义行为。
5. **错**。动态对象不跟随裸指针的作用域自动释放；失去最后管理路径会造成泄漏。

## 二、代码分析

### A

输出为 `4 1`。`values` 仍是实际数组时，整个数组大小除以单个元素大小得到 4；数组到指针转换后，`pointer` 指向首元素，所以比较为真。指针本身不保存元素数量。

### B

`first` 有 4 个元素，包括结尾 `\0`，是有效 C 字符串；`second` 只有 3 个非零字符，不是终止字符串。`strlen(second)` 会越过数组继续寻找终止字符，越界访问属于未定义行为。

### C

- `new[]` 配普通 `delete`：释放形式不匹配，未定义行为。
- 同一动态对象重复 `delete`：双重释放，未定义行为。
- `delete` 后读取 `*c`：释放后使用，未定义行为。

三者都不保证崩溃、异常或固定输出，调试器和 Sanitizer 的检测结果也不能替代语言分类。
