# 第 4 天答案与解析

## 一、概念判断

1. **对**。形参描述函数接口中的输入位置，实参为一次具体调用提供表达式。
2. **错**。值传递建立独立的非引用形参对象；修改基本类型形参不会修改调用方原对象。
3. **错**。返回类型不能单独区分重载，编译器不能只根据结果将被怎样使用来选择这种同参数函数。
4. **错**。默认实参在调用点补足同一个函数的输入，不会创建新函数。
5. **对**。停止条件必须可达；若递归参数不变化，就算写了停止分支也可能永远无法进入。

## 二、代码分析

### 题 A

精确输出：

```text
5 7
```

函数内被修改的是独立形参对象 `value`。`original` 仍为 `5`，函数返回的 `7` 用于初始化 `result`。

### 题 B

精确输出：

```text
int
double
```

整数文字 `2` 的类型为 `int`，`show(int)` 无需转换；`2.5` 的类型为 `double`，`show(double)` 无需转换。各自的精确匹配优于需要转换的另一个候选。

### 题 C

`classify(0)` 沿正常路径到达非 `void` 函数末尾却没有返回值，属于**未定义行为**。编译器可能警告，并且本课程的 `-Werror` 会把相应警告升级为构建失败；这不改变 C++ 语言规则对该执行路径的分类。修复为覆盖非正数路径，例如明确 `return 0;`。

## 三、小型编程题

完整答案见 [`mission_score.cpp`](mission_score.cpp)。关键点是：

- `advance_tasks` 返回新值，调用方原对象保持不变；

## 四、深度思考题参考

可以设计 `int mission_score(int completed_tasks, int points_per_task = 10)`。返回类型和名称直接表达结果；两个参数都按值传递，因此函数不会修改调用方原对象。负数输入可以在调用前拒绝，或让函数返回约定错误值，但约定必须写清，后续异常课程会提供更系统的失败表达。这里不需要重载：默认实参已经解决常用分值；也不需要递归，因为一次乘法比递归累加更清晰、更直接。
