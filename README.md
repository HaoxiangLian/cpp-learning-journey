# C++ Learning Journey

这是皓翔廉的 C++17 基础重建与秋招学习仓库。

这套课程面向“能够阅读算法逻辑，但 C++ 语法、术语和程序运行模型基础较薄弱”的学习阶段，共 28 个学习单元，每单元约 90～120 分钟。

## 学习目标

- 从零建立 C++ 的语法与术语体系
- 理解变量、函数、对象、作用域、栈、堆、指针和生命周期
- 掌握类、RAII、智能指针、多态、模板与 STL
- 具备多文件工程、CMake、调试、测试与基础并发能力
- 能够解释代码，而不只是依赖 vibe coding 得到结果

## 学习方式

每个单元采用以下循环：

1. 读懂最小示例
2. 在运行前预测结果
3. 亲自编译并运行
4. 修改代码并观察变化
5. 脱离示例重新写一遍
6. 在 ChatGPT 对话中提交答案、提问和复盘

核心知识点会依次说明：

> 通俗理解 → 准确定义 → 最小代码 → 执行过程 → 常见错误
