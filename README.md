# C++ Learning Journey

这是皓翔廉的 C++17 基础重建、完整模型与工程实践学习仓库。

课程现为 36 个学习单元，每单元通常约 90～120 分钟。课程面向基础仍在重建的学习者，但不会通过删除真实过程来降低难度：复杂知识先展示完整地图，再逐层深入。

## 学习目标

- 从零建立准确的 C++ 语法与术语体系
- 理解源文件如何经过预处理、狭义编译、汇编和链接成为可执行文件
- 区分对象、名称、作用域、存储期、生命周期和链接
- 掌握函数、类、RAII、智能指针、多态、模板与 STL
- 具备多文件工程、CMake、调试、测试和基础并发能力
- 能解释代码和构建过程，而不只是得到运行结果

## 教学原则

每个复杂主题遵循：

> 完整知识地图 → 今日深入范围 → 准确定义 → 最小示例 → 真实过程跟踪 → 错误实验 → 后续补全节点

如果为了前置知识暂时使用近似解释，讲义必须明确标注，并将缺失部分登记到 [知识完整性与补全追踪表](COVERAGE_MAP.md)。

## 学习方式

1. 先看完整知识地图，知道当前内容位于哪里
2. 读懂最小示例
3. 在运行前预测结果
4. 亲自编译并运行
5. 观察中间产物、诊断信息或变量变化
6. 修改代码并观察差异
7. 脱离示例重新写一遍
8. 将答案直接填写在每道练习题下方
9. 同步到 GitHub 后，在 ChatGPT 对话中请求批改和复盘
10. 根据批改订正，达到标准后再标记完成

练习作答区只保留空白，不使用“在这里作答”等占位文字。
