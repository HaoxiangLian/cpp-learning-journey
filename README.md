# C++ Learning Journey

这是皓翔廉的 C++17 求职向学习仓库，面向“硕士阶段、机器人/机械方向、C++ 基础仍需重建”的学习者。

本课程现在有 36 个完整单元。目标不是把术语讲得更多，而是让你能运行、调试、解释并在面试中用代码证据回答。

## 先从这里开始

1. 打开 [36 单元学习计划](LEARNING_PLAN.md)，只看当前单元，不赶日历进度。
2. 每份讲义先完成“第一遍：先把一个具体问题学会”。
3. 完成对应练习的四类任务：概念检查、可运行编程、调试、面试口述。
4. 第一遍达到标准后，再读“第二遍：完整专业细节”。
5. 个人进度只按练习批改更新，见 [PROGRESS.md](PROGRESS.md)。

如果第一遍仍不能说出“哪个对象、值或文件在什么语句前后发生了什么”，先回到示例改输入、写预测、运行；不要继续堆术语。

## 为什么重做

旧版的主要问题不是知识点太少，而是教学顺序不适合基础薄弱者：

- 大量术语和知识地图出现在真实问题之前；
- “分析、优化、生成较低层表示”等抽象动词没有跟着具体输入、变化和输出；
- 同一天概念过多，却没有说明哪些是第一遍必学、哪些可以暂缓；
- 练习偏问答，缺少可运行任务、故障定位、预期输出和验收标准；
- 面试答案容易变成背诵，不能由实验推导。

修订后的固定顺序是：

> 具体问题 → 最小代码 → 状态变化表 → 只引入必要术语 → 可运行任务 → 故障实验 → 面试表达 → 第二遍专业细节

详细审计与改动证据见 [课程重做报告](COURSE_REBUILD_REPORT.md)。

## 求职能力主线

| 阶段 | 单元 | 必须形成的求职证据 |
|---|---:|---|
| 语言与构建基础 | 1～9 | 能独立写小程序，并解释源码、构建、运行、函数和数据流 |
| 内存、翻译单元与调试 | 10～18 | 能解释生命周期、指针、链接错误、UB，并使用调试工具 |
| 类、资源与接口 | 19～26 | 能使用 RAII、复制/移动、智能指针和多态完成设备模型 |
| STL 与工程可靠性 | 27～35 | 能使用容器、算法、文件、错误策略、CMake、测试和线程 |
| 综合项目与面试 | 36 | 能展示可复现项目，并用代码、诊断和测试证据说明取舍 |

## 每单元完成标准

- [ ] 用 C++17 严格警告构建正常示例；
- [ ] 运行前写输出或故障阶段预测；
- [ ] 保存实际输出/关键诊断并解释第一处差异；
- [ ] 独立完成一个可运行任务；
- [ ] 修复一个故障并用新输入回归验证；
- [ ] 用 30～60 秒回答核心面试题；
- [ ] 能指出当前模型的一个限制和后续补全位置。

## 基本构建约定

普通单文件示例：

```bash
g++ -std=c++17 -Wall -Wextra -pedantic path/to/main.cpp -o build/example
```

内存问题按讲义加入 ASan/UBSan；线程示例加入 `-pthread`；第 33 天开始使用 CMake。Windows PowerShell 的等价命令写在对应讲义中。
