## 练习 1

四个真假结果都正确。

原因不应只写“为真”或“为假”，最好指出参与比较的实际值。例如：

- `battery < 20.0` 为 `false`，因为 `35.0 < 20.0` 不成立
- `battery >= 20.0 && battery < 50.0` 为 `true`，因为两个子条件都成立
- `mode == 1 || mode == 2` 为 `true`，因为右侧 `2 == 2` 成立
- `!ready` 为 `true`，因为 `ready` 是 `false`，逻辑非会取反

## 练习 4

前三问正确。你选择“把 `doubled` 声明移到 `if` 外”也是一种可行修复。

当前代码不能编译，因为：

```cpp
int doubled{}；
```

末尾使用的是中文全角分号 `；`，C++ 源代码需要半角分号 `;`。

修正版本：

```cpp
#include <iostream>

int main() {
    int speed{10};
    int doubled{};

    if (speed > 0) {
        doubled = speed * 2;
        std::cout << doubled << '\n';
    }

    std::cout << doubled << '\n';
    return 0;
}
```

还要意识到：如果 `speed <= 0`，这份程序最后会输出初始化值 `0`。这是否符合需求，要由程序设计目标决定。

## 练习 5

`switch` 的 `case`、`break` 和 `default` 结构正确。

错误在：

```cpp
std::cin >> mode >> '\n';
```

`>>` 表示从输入流提取数据并写入右侧对象；字符字面量 `'\n'` 不是一个可供输入修改的变量，因此这行不能编译。读取整数只需：

```cpp
std::cin >> mode;
```

完整修正：

```cpp
#include <iostream>

int main() {
    int mode{};
    std::cin >> mode;

    switch (mode) {
        case 1:
            std::cout << "Manual\n";
            break;
        case 2:
            std::cout << "Automatic\n";
            break;
        default:
            std::cout << "Unknown\n";
            break;
    }

    return 0;
}
```

请至少测试输入 `1`、`2` 和一个其他整数。

## 练习 7

当前程序存在四个关键问题：

1. `count{4}` 与要求的第一行 `3` 不一致
2. `while (count <= 0)` 在 `count` 为 `4` 时一开始就是假，所以循环不会执行
3. 先递减再输出会改变预期的第一项
4. `std::string Start{Start};` 是错误的自我初始化；文本必须写成字符串字面量，例如 `"Start"`

正确版本：

```cpp
#include <iostream>

int main() {
    int count{3};

    while (count > 0) {
        std::cout << count << '\n';
        --count;
    }

    std::cout << "Start\n";
    return 0;
}
```

这里的循环不变量可以简单理解为：每轮开始时，`count` 保存“本轮要输出的正整数”。

## 练习 9

五个回答的核心意思都正确。

更准确地补充：

- 代码块是由一对花括号界定的一组语句或声明，但并不是所有花括号都表示语句代码块
- 作用域描述的是“名字可以在哪里被查找到和使用”，不等同于对象的存储期或生命周期
- 循环中是否修改计数变量取决于循环设计；本例需要修改它，让条件最终变为假，否则可能形成死循环
