### 练习 6：独立编写

你已经正确完成了这些设计：

- 为左右关节角度选择 `double`
- 定义平均值变量
- 使用加法和除法计算平均值

程序不能编译的原因是三处输入输出运算符写反：

```cpp
std::cin << left_joint;      // 错误
std::cin << right_joint;     // 错误
std::cout >> average_value;  // 错误
```

参考修复：

```cpp
#include <iostream>

int main() {
    double left_joint{};
    double right_joint{};

    std::cin >> left_joint;
    std::cin >> right_joint;

    double average_value{(left_joint + right_joint) / 2.0};
    std::cout << average_value << '\n';

    return 0;
}
```

因为两个操作数本来就是 `double`，你写 `/ 2` 也能得到小数结果；这里写 `/ 2.0` 是为了更明确地表达“小数除法”的意图。
